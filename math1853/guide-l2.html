Exam guide: Vectors

What the exam asks about chapter L2 and how to answer it: the three question types, a method card for each, and every past-paper question from Dec 2012 to May 2026 with a hint and a full solution. The ideas are taught in the L2 note; this page is for practice.

L2At a glance

This chapter is mostly predictable. Two of the three types are row reduction in disguise: put the vectors in as columns, reduce, and read either the last column (is \(\mathbf b\) in the span?) or the number of pivots (independent? what dimension?). The third type is short proofs and true/false statements about independence; these use the same four or five facts every time. Learn the three cards below, then work through the questions on this page in order.

Exam format
  • No calculators in any sitting since Dec 2022. The numbers in this chapter are chosen to reduce cleanly; if you meet ugly fractions, check your last row operation. Combine rows as \(3R_3+(\alpha-15)R_2\) rather than dividing by an expression.
  • No formula sheet. You must know the definitions of span, linear independence and dimension by heart: proof questions are marked on stating them correctly.
  • Multiple choice since Dec 2024. Dec 2024: 2.5 marks, options A–E (Q4, Q10). Dec 2025: 2 marks, four options (Q7). No working is marked; test each option quickly with a tiny example.
  • Time. 3 hours for 100 marks is about 1.8 minutes per mark. A 5-mark span or independence question should take about 9 minutes including a check.

The three cards

L2.1 Linear combinations and span 8 parts · 7 papers · 2.5–6 marks where printed

Looks like"Is \(\mathbf b\) in the span of …", "can … be expressed as a linear combination of …", "find all the solutions to \(t_1M_1+t_2M_2+t_3M_3=M\)", "do the columns span \(\mathbb R^3\)?", "find the constraint on \(\gamma_1,\gamma_2,\gamma_3\)".

DoAugmented matrix \([\,\mathbf a_1\ \cdots\ \mathbf a_p\mid\mathbf b\,]\) with the vectors as columns; row reduce; \(\mathbf b\) is in the span exactly when no row reads \([\,0\ \cdots\ 0\mid c\,]\) with \(c\ne0\). The solution gives the weights.

WatchA letter in \(\mathbf b\) or in a vector: keep it to the last row and set the right-hand entry of every zero row equal to 0. Matrices are "vectors" too: flatten each one into a column, the same entry order every time.

L2.2 Independence and dimension (numbers) 7 parts · 6 papers · 4–5 marks where printed

Looks like"Are the vectors … linearly independent?", "what is the dimension of the subspace spanned by …? Justify / prove", "add a vector so that the span is \(\mathbb R^3\)".

DoVectors as columns, row reduce, count pivots. Pivots = number of vectors ⇔ independent. Dimension of the span = number of pivots. Justify with the explicit dependence relation read from a non-pivot column.

Watch"Dimension" is the number of pivots, not the number of vectors and not the length of each vector. Shortcuts: more vectors than entries ⇒ dependent; two vectors are dependent only if one is a multiple of the other.

L2.3 Independence: proofs and true/false 5 parts · 5 papers · 2–7 marks

Looks likeVectors with names only (\(\mathbf a_1,\mathbf a_2,\mathbf a_3\), \(\mathbf u,\mathbf v,\mathbf w,\mathbf z\), \(\alpha_i,\beta_j\)); "show that", "true or false?", "which set is independent?", "can we conclude?".

DoStart from the definition: write \(c_1\mathbf v_1+\dots+c_p\mathbf v_p=\mathbf 0\) and ask which \(c\)'s are forced to be 0. For "false" give a counterexample in \(\mathbb R^2\) with numbers.

WatchDependent means some vector is a combination of the others, not every one (Dec 2018 Q2(a)(i)). Applying a matrix keeps dependence but keeps independence only if the matrix is invertible.

Learn the ideas first in the chapter note: linear combinations, Example 1, span, Example 2, linear independence, what dependence means, basis.

How to read the row operations on this page: the label above an arrow names the new row first. \(R_2-2R_1\) means "replace row 2 by row 2 minus 2 times row 1"; \(3R_3+(\alpha-15)R_2\) means "replace row 3 by 3 times row 3 plus \((\alpha-15)\) times row 2" (allowed because the row being replaced is multiplied by the non-zero number 3); \(\tfrac17R_2\) means "divide row 2 by 7".

L2.1Linear combinations and span

8 parts · May 2025, Dec 2024 (MC), May 2023; older format May 2019, Dec 2017, Dec 2015, May 2014 (×2) · Learn it: note §3, §4, §5, §6

Method
  1. Write the augmented matrix \([\,\mathbf a_1\ \mathbf a_2\ \cdots\ \mathbf a_p\mid\mathbf b\,]\): the given vectors are the columns, \(\mathbf b\) is the last column. The unknowns are the weights \(c_1,\dots,c_p\).
    • Matrices instead of vectors: turn each matrix into a column by reading its entries in the same order every time (row by row).
    • Two vectors to test against the same span: put both on the right, \([\,A\mid\mathbf b_1\ \mathbf b_2\,]\), and reduce once.
  2. Row reduce to echelon form (L1 method). Keep any letter (\(\alpha\), \(b_i\), \(\gamma_i\)) in the last rows; never divide by an expression containing it.
  3. Read the rows whose coefficient part is all zeros, \([\,0\ \cdots\ 0\mid g\,]\):
    • numbers: \(g\ne0\) ⇒ \(\mathbf b\) is not in the span; all \(g=0\) ⇒ it is;
    • letters: "in the span" ⇔ every such \(g=0\). That equation is the condition (the "constraint") asked for.
  4. If the weights are asked for, back-substitute. A free variable means infinitely many ways to write \(\mathbf b\); give the general solution or, if one combination is enough, say "taking \(c_3=0\)".
  5. "Do the columns of a square \(A\) span \(\mathbb R^n\)?": yes ⇔ \(\det A\ne0\) ⇔ a pivot in every row. Then reduce with a general \(\mathbf b=[b_1,\dots,b_n]^T\) to get the weights.
  6. "Prove \(\operatorname{span}(\mathbf u\text{'s})=\operatorname{span}(\mathbf w\text{'s})\)": find the constraint for each span (step 3 with \(\mathbf b=[\gamma_1,\gamma_2,\gamma_3]^T\)); equal constraints ⇒ equal spans. Or show each \(\mathbf w\) is a combination of the \(\mathbf u\)'s and each \(\mathbf u\) of the \(\mathbf w\)'s.
Ready answer · span membership \[ \begin{aligned} &\mathbf b\in\operatorname{Span}\{\mathbf a_1,\dots,\mathbf a_p\}\\ &\iff c_1\mathbf a_1+\dots+c_p\mathbf a_p=\mathbf b\ \text{solvable}\\ &\iff [\,\mathbf a_1\ \cdots\ \mathbf a_p\mid\mathbf b\,]\ \text{consistent} \end{aligned} \]

i.e. no row \([\,0\ \cdots\ 0\mid c\,]\) with \(c\ne0\) after reduction.

Two vectors in \(\mathbb R^2\) span all of \(\mathbb R^2\) unless one is a multiple of the other:

\[ \operatorname{Span}\Big\{\begin{bmatrix}p\\q\end{bmatrix},\begin{bmatrix}r\\s\end{bmatrix}\Big\}=\mathbb R^2\iff ps-qr\ne0. \]

Writing the answer: "The last row reads \(0=-3\), which is impossible, so \(\mathbf b\) is not a linear combination of …" or "\(\mathbf b=\tfrac13\mathbf a_1-\tfrac23\mathbf a_2\)", followed by a one-line check.

May 2025 Q15 points

Find all the solutions to the equation:

\[ t_1\begin{bmatrix}1&2\\-2&-1\end{bmatrix}+t_2\begin{bmatrix}1&1\\0&-1\end{bmatrix} \] \[ +\,t_3\begin{bmatrix}2&3\\1&1\end{bmatrix}=\begin{bmatrix}-1&-4\\3&-2\end{bmatrix} \]
Hint

L2.1 with matrices as the vectors. Equal matrices have equal entries: read the four entries row by row to get four equations in \(t_1,t_2,t_3\); each matrix becomes a column of the augmented matrix.

Solution
  1. Entry by entry, in the order \((1,1),(1,2),(2,1),(2,2)\): \[ \begin{aligned} t_1+t_2+2t_3&=-1\\ 2t_1+t_2+3t_3&=-4\\ -2t_1+t_3&=3\\ -t_1-t_2+t_3&=-2 \end{aligned} \]
  2. \[ \left[\begin{array}{ccc|c}1&1&2&-1\\2&1&3&-4\\-2&0&1&3\\-1&-1&1&-2\end{array}\right] \]

    \(\xrightarrow{\;R_2-2R_1,\ R_3+2R_1,\ R_4+R_1\;}\)

    \[ \left[\begin{array}{ccc|c}1&1&2&-1\\0&-1&-1&-2\\0&2&5&1\\0&0&3&-3\end{array}\right] \]

    \(\xrightarrow{\;R_3+2R_2\;}\)

    \[ \left[\begin{array}{ccc|c}1&1&2&-1\\0&-1&-1&-2\\0&0&3&-3\\0&0&3&-3\end{array}\right] \]

    \(\xrightarrow{\;R_4-R_3\;}\)

    \[ \left[\begin{array}{ccc|c}1&1&2&-1\\0&-1&-1&-2\\0&0&3&-3\\0&0&0&0\end{array}\right] \]
  3. No row \([\,0\ 0\ 0\mid c\ne0\,]\), and a pivot in each of the three columns: exactly one solution.
  4. Back-substitute: \(3t_3=-3\Rightarrow t_3=-1\); \(-t_2-t_3=-2\Rightarrow t_2=3\); \(t_1=-1-t_2-2t_3=-2\).

Marker: show the four scalar equations (or the four-row augmented matrix) and say why the solution is unique: four equations, three pivots, the extra row became zero.

\[ \boxed{t_1=-2,\quad t_2=3,\quad t_3=-1} \]

Check the \((2,2)\) entry: \(-(-2)-3+(-1)=-2\ \checkmark\).

Dec 2024 Q42.5 pointsmultiple choice

The vector \(\begin{bmatrix}1\\\beta\end{bmatrix}\) cannot be expressed as a linear combination of \(\begin{bmatrix}\alpha\\2\end{bmatrix}\) and \(\begin{bmatrix}-2\\1\end{bmatrix}\) when ( ).

A. \(\alpha=4,\ \beta\ne-\tfrac13\)   B. \(\alpha=2,\ \beta\ne\tfrac12\)   C. \(\alpha=3,\ \beta\ne\tfrac12\)   D. \(\alpha=-4,\ \beta\ne\tfrac12\)   E. \(\alpha=-3,\ \beta\ne-\tfrac12\)

Reading used: the correct condition is \(\alpha=-4,\ \beta\ne-\tfrac12\), which matches no option. D has the right \(\alpha\) and a sign misprint in \(\beta\); D is the intended answer.

Hint

L2.1 in \(\mathbb R^2\). Two vectors fail to span \(\mathbb R^2\) only when one is a multiple of the other: when is \(\alpha\cdot1-2\cdot(-2)=0\)?

Solution
  1. \(\det\begin{bmatrix}\alpha&-2\\2&1\end{bmatrix}=\alpha+4\). If \(\alpha\ne-4\) the two vectors span \(\mathbb R^2\), so every vector, including \([1,\beta]^T\), is a combination. So we need \(\alpha=-4\).
  2. With \(\alpha=-4\): \([-4,2]^T=2[-2,1]^T\), so the span is the line of multiples \(t[-2,1]^T\).
  3. \([1,\beta]^T=t[-2,1]^T\) needs \(t=-\tfrac12\), so \(\beta=-\tfrac12\). Hence \([1,\beta]^T\) is not a combination exactly when \(\alpha=-4\) and \(\beta\ne-\tfrac12\).
  4. Only D has \(\alpha=-4\); its \(\beta\ne\tfrac12\) is the misprinted sign.

Marker: E is the trap: it has the right \(\beta\ne-\tfrac12\) but \(\alpha=-3\), and for \(\alpha=-3\) the two vectors span \(\mathbb R^2\), so every vector is a combination. A, B, C fail for the same reason.

\[ \boxed{\text{D}} \]

Taken literally, D is not quite right either: with \(\alpha=-4\), \(\beta=-\tfrac12\) (allowed by D) the vector is a combination. Choose D and, if there is space, note the sign.

May 2023 Q25%

Same question with \(\mathbf b=[-3,8,1]^T\): May 2019 Q2.

A set of two vectors \(\mathbf a_1=[1\ \ -2\ \ 3]^T\) and \(\mathbf a_2=[5\ \ -13\ \ \alpha]^T\) forms a basis of a subspace of vectors. If vector \(\mathbf b=[-3\ \ 8\ \ 5]^T\) is in the subspace of vectors that is spanned by \(\mathbf a_1\) and \(\mathbf a_2\), determine the unspecified real number \(\alpha\).

Hint

L2.1 with a letter in a vector. Reduce \([\,\mathbf a_1\ \mathbf a_2\mid\mathbf b\,]\) with \(R_2+2R_1\), \(R_3-3R_1\); then clear the \(\alpha-15\) in row 3 using row 2 without dividing by it.

Solution
  1. \[ \left[\begin{array}{cc|c}1&5&-3\\-2&-13&8\\3&\alpha&5\end{array}\right] \]

    \(\xrightarrow{\;R_2+2R_1,\ R_3-3R_1\;}\)

    \[ \left[\begin{array}{cc|c}1&5&-3\\0&-3&2\\0&\alpha - 15&14\end{array}\right] \]

    \(\xrightarrow{\;3R_3+(\alpha-15)R_2\;}\)

    \[ \left[\begin{array}{cc|c}1&5&-3\\0&-3&2\\0&0&2 \alpha + 12\end{array}\right] \]
  2. Row 3 is \([\,0\ \ 0\mid 2\alpha+12\,]\). \(\mathbf b\) is in the span exactly when this row is zero: \(2\alpha+12=0\), so \(\alpha=-6\).
  3. Weights (not asked, but a good check): row 2 gives \(-3c_2=2\), \(c_2=-\tfrac23\); row 1 gives \(c_1=-3-5c_2=\tfrac13\).

Marker: say why the last row must vanish ("\(\mathbf b\) in the span ⇔ the system is consistent"); the value of \(\alpha\) alone with no reason is weak.

\[ \boxed{\alpha=-6} \]

Check: \(\tfrac13\mathbf a_1-\tfrac23\mathbf a_2\) has third entry \(\tfrac13(3)-\tfrac23(-6)=1+4=5\ \checkmark\). \(\mathbf a_1,\mathbf a_2\) are independent for every \(\alpha\) (\(1:-2\ne5:-13\)), so "basis" holds.

May 2019 Q26 marksolder format

Same question with \(\mathbf b=[-3,8,5]^T\): May 2023 Q2.

Assuming a set of the two vectors \(\mathbf a_1=[1,-2,3]^T\) and \(\mathbf a_2=[5,-13,\alpha]^T\) forms the basis of a subspace of vectors. If the vector \(\mathbf b=[-3,8,1]^T\) is in the subspace of vectors that is spanned by \(\mathbf a_1\) and \(\mathbf a_2\), determine the unspecified real number \(\alpha\).

Hint

L2.1, exactly as May 2023 Q2; only the last entry of \(\mathbf b\) changes, so only the last entry of row 3 changes.

Solution
  1. \[ \left[\begin{array}{cc|c}1&5&-3\\-2&-13&8\\3&\alpha&1\end{array}\right] \]

    \(\xrightarrow{\;R_2+2R_1,\ R_3-3R_1\;}\)

    \[ \left[\begin{array}{cc|c}1&5&-3\\0&-3&2\\0&\alpha - 15&10\end{array}\right] \]

    \(\xrightarrow{\;3R_3+(\alpha-15)R_2\;}\)

    \[ \left[\begin{array}{cc|c}1&5&-3\\0&-3&2\\0&0&2 \alpha\end{array}\right] \]
  2. Row 3 is \([\,0\ \ 0\mid 2\alpha\,]\). In the span ⇔ \(2\alpha=0\) ⇔ \(\alpha=0\).
  3. Weights: as before \(c_2=-\tfrac23\), \(c_1=\tfrac13\).
\[ \boxed{\alpha=0} \]

Check: third entry of \(\tfrac13\mathbf a_1-\tfrac23\mathbf a_2\) is \(1-\tfrac23(0)=1\ \checkmark\).

Dec 2017 Q2(a)10 points for (a), (b)older format

Part (b), determinants after row operations: L4 guide.

Do the column vectors in \(\begin{bmatrix}1&1&0\\1&1&1\\0&1&1\end{bmatrix}\) span the whole \(\mathbb R^3\)? If yes, please find the linear combination of the column vectors that span \(\begin{bmatrix}b_1\\b_2\\b_3\end{bmatrix}\in\mathbb R^3\).

Hint

L2.1, square case. Reduce \([\,A\mid\mathbf b\,]\) with a general \(\mathbf b\): \(R_2-R_1\), then swap rows 2 and 3. A pivot in every row means yes.

Solution
  1. Call the columns \(\mathbf c_1,\mathbf c_2,\mathbf c_3\) and solve \(x_1\mathbf c_1+x_2\mathbf c_2+x_3\mathbf c_3=\mathbf b\):
    \[ \left[\begin{array}{ccc|c}1&1&0&b_{1}\\1&1&1&b_{2}\\0&1&1&b_{3}\end{array}\right] \]

    \(\xrightarrow{\;R_2-R_1\;}\)

    \[ \left[\begin{array}{ccc|c}1&1&0&b_{1}\\0&0&1&- b_{1} + b_{2}\\0&1&1&b_{3}\end{array}\right] \]

    \(\xrightarrow{\;R_2\leftrightarrow R_3\;}\)

    \[ \left[\begin{array}{ccc|c}1&1&0&b_{1}\\0&1&1&b_{3}\\0&0&1&- b_{1} + b_{2}\end{array}\right] \]
  2. A pivot in every row (and every column), so the system is consistent for every \(\mathbf b\): yes, the columns span \(\mathbb R^3\). (Equivalently \(\det A=-1\ne0\).)
  3. Back-substitute: \(x_3=b_2-b_1\); \(x_2=b_3-x_3=b_1-b_2+b_3\); \(x_1=b_1-x_2=b_2-b_3\).
\[ \boxed{\begin{aligned} \mathbf b&=(b_2-b_3)\,\mathbf c_1\\ &\quad+(b_1-b_2+b_3)\,\mathbf c_2\\ &\quad+(b_2-b_1)\,\mathbf c_3 \end{aligned}} \]

Check row 2:

\[ \begin{aligned} &x_1+x_2+x_3\\ &=(b_2-b_3)+(b_1-b_2+b_3)\\ &\quad+(b_2-b_1)=b_2\ \checkmark \end{aligned} \]

The weights are \(A^{-1}\mathbf b\).

Dec 2015 Q3(b)5 pointsolder format

Part (a), equal determinants: L4 guide. Parts (c), (d), definiteness: earlier-syllabus questions.

Do the vectors \(\begin{bmatrix}1\\1\\-1\end{bmatrix}\) and \(\begin{bmatrix}-1\\0\\-1\end{bmatrix}\) lie in \(\operatorname{span}\left(\begin{bmatrix}-1\\1\\0\end{bmatrix},\begin{bmatrix}1\\2\\3\end{bmatrix},\begin{bmatrix}1\\5\\6\end{bmatrix}\right)\)?

Hint

L2.1 with two right-hand sides: reduce \([\,\mathbf v_1\ \mathbf v_2\ \mathbf v_3\mid\mathbf b_1\ \mathbf b_2\,]\) once (\(R_2+R_1\), then \(R_3-R_2\)) and read each right-hand column separately.

Solution
  1. \[ \left[\begin{array}{ccc|cc}-1&1&1&1&-1\\1&2&5&1&0\\0&3&6&-1&-1\end{array}\right] \]

    \(\xrightarrow{\;R_2+R_1\;}\)

    \[ \left[\begin{array}{ccc|cc}-1&1&1&1&-1\\0&3&6&2&-1\\0&3&6&-1&-1\end{array}\right] \]

    \(\xrightarrow{\;R_3-R_2\;}\)

    \[ \left[\begin{array}{ccc|cc}-1&1&1&1&-1\\0&3&6&2&-1\\0&0&0&-3&0\end{array}\right] \]
  2. The coefficient part of row 3 is zero, so the three spanning vectors span only a plane (\(\mathbf v_3=\mathbf v_1+2\mathbf v_2\)).
  3. First vector: row 3 reads \(0=-3\), impossible. So \([1,1,-1]^T\) is not in the span.
  4. Second vector: row 3 reads \(0=0\); consistent, so \([-1,0,-1]^T\) is in the span. With \(c_3=0\): \(3c_2=-1\), \(c_2=-\tfrac13\); \(-c_1+c_2=-1\), \(c_1=\tfrac23\).
\[ \boxed{\begin{gathered}[1,1,-1]^T:\ \text{no}\\ [-1,0,-1]^T:\ \text{yes},\\ =\tfrac23\mathbf v_1-\tfrac13\mathbf v_2 \end{gathered}} \]

Check:

\[ \begin{aligned} &\tfrac23[-1,1,0]^T-\tfrac13[1,2,3]^T\\ &\quad=[-1,0,-1]^T\ \checkmark \end{aligned} \]

The general combination is \(\big(\tfrac23-c_3\big)\mathbf v_1+\big(-\tfrac13-2c_3\big)\mathbf v_2+c_3\mathbf v_3\).

May 2014 Q2(b), (c)15 points for (a)–(d)older format

Parts (a), (d), dimension and extending to \(\mathbb R^3\): L2.2 on this page.

Let \(\mathbf u_1=[1\ \ 1\ \ -1]^T\), \(\mathbf u_2=[2\ \ 3\ \ -1]^T\) and \(\mathbf u_3=[3\ \ 1\ \ -5]^T\).

(b) Find the constraint on \(\gamma_1,\gamma_2\) and \(\gamma_3\) such that \([\gamma_1\ \gamma_2\ \gamma_3]^T\) can be expressed as a linear combination of \(\mathbf u_1,\mathbf u_2\) and \(\mathbf u_3\).
(c) Prove that \(\operatorname{span}(\mathbf u_1,\mathbf u_2,\mathbf u_3)=\operatorname{span}(\mathbf w_1,\mathbf w_2,\mathbf w_3)\), where \(\mathbf w_1=[1\ \ -1\ \ -3]^T\), \(\mathbf w_2=[3\ \ -2\ \ -8]^T\) and \(\mathbf w_3=[2\ \ 1\ \ -3]^T\).

Hint

L2.1 with letters on the right. (b) Reduce \([\,\mathbf u_1\ \mathbf u_2\ \mathbf u_3\mid\boldsymbol\gamma\,]\): \(R_2-R_1\), \(R_3+R_1\), \(R_3-R_2\). (c) Do the same for the \(\mathbf w\)'s and compare the two constraints.

Solution

(b)

  1. \[ \left[\begin{array}{ccc|c}1&2&3&\gamma_{1}\\1&3&1&\gamma_{2}\\-1&-1&-5&\gamma_{3}\end{array}\right] \]

    \(\xrightarrow{\;R_2-R_1,\ R_3+R_1\;}\)

    \[ \left[\begin{array}{ccc|c}1&2&3&\gamma_{1}\\0&1&-2&- \gamma_{1} + \gamma_{2}\\0&1&-2&\gamma_{1} + \gamma_{3}\end{array}\right] \]

    \(\xrightarrow{\;R_3-R_2\;}\)

    \[ \left[\begin{array}{ccc|c}1&2&3&\gamma_{1}\\0&1&-2&- \gamma_{1} + \gamma_{2}\\0&0&0&2 \gamma_{1} - \gamma_{2} + \gamma_{3}\end{array}\right] \]
  2. Row 3 has zero coefficient part, so the system is consistent exactly when its right-hand entry is 0.
\[ \boxed{2\gamma_1-\gamma_2+\gamma_3=0} \]

(c)

  1. By (b), \(\operatorname{span}(\mathbf u_1,\mathbf u_2,\mathbf u_3)\) is the set of all \(\boldsymbol\gamma\) with \(2\gamma_1-\gamma_2+\gamma_3=0\).
  2. Same method for the \(\mathbf w\)'s:
    \[ \left[\begin{array}{ccc|c}1&3&2&\gamma_{1}\\-1&-2&1&\gamma_{2}\\-3&-8&-3&\gamma_{3}\end{array}\right] \]

    \(\xrightarrow{\;R_2+R_1,\ R_3+3R_1\;}\)

    \[ \left[\begin{array}{ccc|c}1&3&2&\gamma_{1}\\0&1&3&\gamma_{1} + \gamma_{2}\\0&1&3&3 \gamma_{1} + \gamma_{3}\end{array}\right] \]

    \(\xrightarrow{\;R_3-R_2\;}\)

    \[ \left[\begin{array}{ccc|c}1&3&2&\gamma_{1}\\0&1&3&\gamma_{1} + \gamma_{2}\\0&0&0&2 \gamma_{1} - \gamma_{2} + \gamma_{3}\end{array}\right] \]
  3. So \(\operatorname{span}(\mathbf w_1,\mathbf w_2,\mathbf w_3)\) is also the set of all \(\boldsymbol\gamma\) with \(2\gamma_1-\gamma_2+\gamma_3=0\).
  4. Both spans are the same set of vectors, hence equal. \(\blacksquare\)

Marker: a proof of equal spans needs both directions; checking only that each \(\mathbf w_j\) satisfies the constraint shows one inclusion, not equality.

Explicit combinations, if you prefer two inclusions: \[ \begin{aligned} \mathbf w_1&=5\mathbf u_1-2\mathbf u_2\\ \mathbf w_2&=13\mathbf u_1-5\mathbf u_2\\ \mathbf w_3&=4\mathbf u_1-\mathbf u_2\\ \mathbf u_1&=-5\mathbf w_1+2\mathbf w_2\\ \mathbf u_2&=-13\mathbf w_1+5\mathbf w_2\\ \mathbf u_3&=-9\mathbf w_1+4\mathbf w_2 \end{aligned} \]

L2.2Independence and dimension of a span

7 parts · Dec 2023, May 2023; older format May 2018, May 2017, May 2015, May 2014 (×2) · Learn it: note §7, §8, §9

Method
  1. Try the shortcuts first:
    • more vectors than entries (\(p\gt n\) in \(\mathbb R^n\)) ⇒ dependent;
    • a zero vector in the set ⇒ dependent;
    • two vectors ⇒ dependent only if one is a multiple of the other (compare entry ratios);
    • \(n\) vectors in \(\mathbb R^n\) ⇒ independent ⇔ \(\det\ne0\).
  2. Otherwise put the vectors in as the columns of a matrix \(A=[\,\mathbf v_1\ \cdots\ \mathbf v_p\,]\) (no right-hand side: the system \(A\mathbf c=\mathbf 0\) is homogeneous) and row reduce to echelon form.
  3. Count the pivots \(r\).
    • \(r=p\) (a pivot in every column) ⇒ independent; \(r\lt p\) ⇒ dependent.
    • Dimension of the span \(=r\); a basis is the original vectors in the pivot columns.
  4. To justify "dependent", write the relation: set a free variable to 1 and back-substitute to get \(\mathbf v_k\) as a combination of the pivot-column vectors. Check it with numbers.
  5. To extend to a spanning set of \(\mathbb R^n\): add a vector that is not in the span (it fails the span condition of L2.1), and say why the new set has \(n\) pivots.
Ready answer · dimension of a span \[ \begin{aligned} &\dim\operatorname{Span}\{\mathbf v_1,\dots,\mathbf v_p\}\\ &\quad=\text{number of pivots of }[\,\mathbf v_1\ \cdots\ \mathbf v_p\,] \end{aligned} \]

L2.3Independence: proofs and true/false

5 parts · Dec 2025 (MC), Dec 2024 (MC), Dec 2023; older format Dec 2018, Dec 2013 · Learn it: note §7, §8, §14 Concept checks

Method · decision procedure
  1. Write the definition for the set in question: \(c_1\mathbf v_1+\dots+c_p\mathbf v_p=\mathbf 0\). Independent ⇔ this forces every \(c_i=0\); dependent ⇔ some solution has a \(c_i\ne0\).
  2. New vectors built from independent ones (e.g. \(\mathbf a_1+\mathbf a_3\), \(\mathbf a_1-\mathbf a_2\)):
    • first look for an obvious relation: do they add to \(\mathbf 0\)? is one a combination of the others? If so, dependent;
    • if not, substitute, collect the coefficient of each \(\mathbf a_i\), and set each to 0 (allowed because the \(\mathbf a_i\) are independent). Solve the small system for the \(c\)'s.
  3. A dependent set containing an independent one: in the relation, the coefficient of the extra vector cannot be 0 (otherwise the independent part would be dependent). Divide by it: the extra vector is a combination of the rest.
  4. A matrix applied to vectors: apply \(A\) to the relation. Dependence always survives (\(A\mathbf 0=\mathbf 0\)). Independence survives when \(A\) is invertible: multiply by \(A^{-1}\). For "can we conclude?" try \(A=0\).
  5. "Show that … is not …": argue by contradiction: suppose it is, substitute, and contradict a given independence.
  6. True/false: a statement about all vectors is false if one example breaks it. Try, in \(\mathbb R^2\): a repeated vector, the zero vector, \(\boldsymbol\beta_i=-\boldsymbol\alpha_i\), or \(\mathbf e_1,2\mathbf e_1,\mathbf e_2\). If no example breaks it, prove it from the definition.
Ready answer · facts to quote
  • A subset of an independent set is independent. A set containing \(\mathbf 0\), or a repeated vector, is dependent.
  • If \(\mathbf v_1,\dots,\mathbf v_p\) are independent and \(\mathbf v_1,\dots,\mathbf v_p,\mathbf w\) are dependent, then \(\mathbf w\in\operatorname{Span}\{\mathbf v_1,\dots,\mathbf v_p\}\).
  • Dependent ⇔ at least one vector is a combination of the others (not necessarily every one).
  • More than \(n\) vectors in \(\mathbb R^n\) are dependent.
