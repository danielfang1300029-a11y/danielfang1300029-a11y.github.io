Probability theory

0Where this chapter sits

Probability measures how likely something is when you cannot predict the outcome. This chapter builds the language that P3 and P4 use, on four pictures: counting is filling slots; conditioning shrinks the world to the cases where something happened; Bayes reasons backwards from a test result along a tree of branches; and independence means one event tells you nothing about the other. (MATH1853 Part I, chapters L1 to L7, is linear algebra; Part II is P1 complex variables, P2 probability theory, P3 common distributions and P4 elementary statistical inference.)

1Counting: the fundamental rule ~5 min

What is this?

Picture a row of empty slots that you fill one at a time: the first slot is "which tie", the second is "which shirt". Each way of filling the first slot starts its own list of ways to fill the second. So the counts multiply, not add. Every counting question in this chapter is a question about filling slots.

Many probabilities are "number of favourable cases divided by number of all cases" (section 7), so the chapter starts by learning to count: permutations and combinations.

Basic question

A man has two ties and three shirts. In how many ways can he dress up (put on one of each)? Do we add, \(2+3\)? Multiply, \(2\times3\)? Or perhaps \(2^3\) or \(3^2\)?

For an example this small you can simply list the possibilities. Call the ties \(t_1,t_2\) and the shirts \(s_1,s_2,s_3\). The outfits are

\[ \begin{aligned} &(t_1,s_1),\ (t_1,s_2),\ (t_1,s_3),\\ &(t_2,s_1),\ (t_2,s_2),\ (t_2,s_3). \end{aligned} \]

The answer is \(6=2\times3\): for each of the 2 ties there is a full row of 3 shirts.

Fundamental Rule

A number of multiple choices are to be made. There are \(m_1\) possibilities for the first choice, \(m_2\) for the second, \(m_3\) for the third, and so on. If these choices can be combined freely, then the total number of possibilities for the whole set of choices is the product

\[ m_1\times m_2\times m_3\times\cdots\times m_{\text{last}}. \]

In words: when you make several choices one after another, and every choice can go with every other, multiply the numbers of options.

Reading the formula
\(m_1\)
the number of options for the first slot.
\(m_1\times m_2\)
each of the \(m_1\) options for slot 1 starts its own row of \(m_2\) options for slot 2, like the rows of ties and shirts above.
\(\times\cdots\times m_{\text{last}}\)
each further slot multiplies the number of ways again.
"combined freely"
every option for one slot can go with every option for the others. If some pairs are forbidden, the product over-counts and you must count the allowed ones.

Remark. "Free combination" in the tie-and-shirt example means that no matching of shirt and tie is required: every tie may be worn with every shirt. If some combinations were forbidden (say \(t_1\) clashes with \(s_3\)), you could not just multiply; you would count the allowed pairs (here \(6-1=5\)).

2Sampling and combinations ~12 min

What is this?

Drawing \(r\) balls is filling \(r\) slots. If each ball goes back, every slot has all \(n\) options. If it stays out, each slot has one option fewer than the slot before. And if only the final group matters, not the order of the slots, several fillings describe the same group and must be counted once.

Here is a model that covers almost every counting question: an urn contains \(n\) distinguishable balls marked 1 to \(n\), and \(r\) balls are drawn from it. The answer depends on two questions: is each ball put back before the next draw (with or without replacement)? And does the order of the draws matter (with or without ordering)? That gives four cases, (I), (II), (III) here and (V) in section 3.

(I) Sampling with replacement and with ordering

We draw \(r\) balls one after another, each ball drawn being put back into the urn before the next draw. Every draw has \(n\) possible results, so by the fundamental rule the number of possible outcomes is

\[ \underbrace{n\times n\times\cdots\times n}_{r\text{ times}}=n^r. \]

Here \(r\) can be any positive integer (even bigger than \(n\), since balls are put back).

In words: \(r\) independent choices from \(n\) options each, order recorded: \(n^r\). Example: a 4-digit PIN uses digits 0 to 9 with repeats allowed, so there are \(10^4\) PINs.

(II) Sampling without replacement and with ordering

Now a drawn ball is kept out, so \(r\le n\). The first choice can be any one of the \(n\) balls, but the second must be a different one: after the first choice there are \(n-1\) choices for the second. Which \(n-1\) balls depends on the first choice, but their number does not. So there are \(n(n-1)\) ways for the first two choices together, then \(n-2\) for the third, and so on:

\[ \begin{aligned} &n(n-1)(n-2)\cdots(n-r+1)\\ &\qquad=:P^n_r={}_nP_r. \end{aligned} \]

If \(r=n\), then \(P^n_n=n!\) = the number of ways to position, arrange or order \(n\) balls.

In words: \(P^n_r\) ("permutations") counts ordered lists of \(r\) different objects from \(n\): multiply \(r\) numbers counting down from \(n\). It equals \(\dfrac{n!}{(n-r)!}\).

The symbol \(=:\) means "which we call". \(n!\) ("\(n\) factorial") is \(n(n-1)\cdots2\cdot1\), with \(0!=1\).

What is this? (choosing without order)

A committee of 3 is a group, not a queue. Fill 3 slots in order as before, then notice that the same three people can stand in the slots in \(3!=6\) orders. Each committee has been counted 6 times, so divide by 6.

(III) Sampling without replacement and without ordering

Suppose the urn has 7 balls \(b_1,\dots,b_7\) and we sample 3. The six ordered samples

\[ \begin{aligned} &(b_2,b_3,b_5),\ (b_2,b_5,b_3),\ (b_3,b_2,b_5),\\ &(b_3,b_5,b_2),\ (b_5,b_2,b_3),\ (b_5,b_3,b_2) \end{aligned} \]

are part of the \(P^7_3\) possibilities of case (II). If we only care which balls are chosen, not the order, these \(6=3!\) samples count as one. Writing \(N\) for the number of ways to choose 3 balls out of 7,

\[ \underbrace{3!}_{\text{orders of these 3}}\times\underbrace{N}_{\text{choose 3 of 7}}=\underbrace{P^7_3}_{\text{choose 3 of 7 in order}}. \]

In general we define

\[ {}_nC_r=C^n_r=\binom nr \]

= the number of ways to choose \(r\) objects out of a collection of \(n\) objects. The same argument gives \(r!\times C^n_r=P^n_r\), and so

\[ \begin{aligned} \binom nr&=\frac{P^n_r}{r!}=\frac{n(n-1)\cdots(n-r+1)}{r!}\\ &=\frac{n!}{r!\,(n-r)!}. \end{aligned} \]

In words: to count unordered selections, count ordered ones and divide by the \(r!\) orders in which each selection can appear. \(\binom nr\) is read "\(n\) choose \(r\)".

Reading the formula
\(n(n-1)\cdots(n-r+1)\)
fill \(r\) slots in order, one ball fewer to choose from each time.
\(r!\)
the number of orders in which one chosen group can sit in the \(r\) slots.
\(\dfrac{P^n_r}{r!}\)
each group was counted once for every order; dividing counts it once.
\(\dfrac{n!}{r!\,(n-r)!}\)
the same number: \(n!/(n-r)!\) is the ordered count, because the \((n-r)!\) cancels the balls you never draw.

For 3 balls out of 7: \(P^7_3=7\cdot6\cdot5=210\), so \(N=\binom73=210/6=35\).

Exercise 2.2

Show that \(\displaystyle\binom nr=\binom n{n-r}\).

Solution. By the formula, \[ \begin{aligned} \binom n{n-r}&=\frac{n!}{(n-r)!\,(n-(n-r))!}\\ &=\frac{n!}{(n-r)!\,r!}=\binom nr. \end{aligned} \] In words: choosing the \(r\) objects you take is the same as choosing the \(n-r\) objects you leave, so the two counts agree.

Example

Three balls are selected from a box of four balls numbered 1, 2, 3 and 4. How many different possible combinations are there?

List all \(24=P^4_3=4\cdot3\cdot2\) permutations, one row for each set of three numbers:

\[ \begin{array}{ccc} (1,2,3)&(1,3,2)&(2,1,3)\\ (1,2,4)&(1,4,2)&(2,1,4)\\ (1,3,4)&(1,4,3)&(3,1,4)\\ (2,3,4)&(2,4,3)&(3,2,4) \end{array} \]

and, continuing each row,

\[ \begin{array}{ccc} (2,3,1)&(3,1,2)&(3,2,1)\\ (2,4,1)&(4,1,2)&(4,2,1)\\ (3,4,1)&(4,1,3)&(4,3,1)\\ (3,4,2)&(4,2,3)&(4,3,2) \end{array} \]

If we disregard the ordering, each row is one set: every entry of row 1 becomes \(\{1,2,3\}\), and so on. Clearing the repetitions leaves

\[ \{\{1,2,3\},\{1,2,4\},\{1,3,4\},\{2,3,4\}\}, \]

a set of 4 elements. Therefore the answer is

\[ \frac{P^4_3}{3!}=\binom43=4. \]

This makes the formula \(r!\times C^n_r=P^n_r\) explicit: \(3!\times4=24\) (6 columns, 4 rows).

Exercise 2.3

Let \(A=\{1,2,3,4,5,6\}\). How many distinct subsets of \(A\) are there of size 2? (Recall that \(\{1,2\}\subset A\) and \(\{1,2\}=\{2,1\}\).)

Solution. A subset ignores order, so this is case (III): \(\binom62=\dfrac{6\cdot5}{2!}=15\).

Remark: brackets

Recall the use of the different "bracket" notations. Round brackets list things in order (as for vectors in Part I), so \((1,2,3)\ne(1,3,2)\). Braces make sets, where order does not matter, so \(\{1,2,3\}=\{1,3,2\}\). Ordered samples are written with \((\ )\), unordered ones with \(\{\ \}\).

The counting cases side by side

The default \(n=7\), \(r=3\) is the urn of case (III): 210 ordered samples, 35 unordered. Case (V) is in section 3. Without replacement, \(r\) cannot exceed \(n\).

Exercise 2.4

Here is the working for each.

1. How many integers are there between 1 million and 10 million in whose decimal form no two consecutive digits are the same?

These integers have 7 digits. The first digit can be 1 to 9 (9 ways). Each later digit can be any of 0 to 9 except the digit just before it (9 ways). By the fundamental rule: \(9^7=4\,782\,969\).Which 9 digits are allowed depends on the slot before, but how many does not, and the fundamental rule only needs how many (as in case (II)). (Ten million itself has 8 digits and repeated zeros, so it does not count.)

2. In a "true or false" test there are 12 questions. If a student decides to check six of them at random, in how many ways can she do it?

She chooses a set of 6 questions out of 12, order irrelevant: \(\binom{12}6=924\).

3. In how many ways can four boys and four girls pair off? In how many ways can they stand in a row in alternating gender?

Pairing: line the boys up in a fixed order; the first boy's partner can be any of 4 girls, the second's any of the remaining 3, and so on: \(4!=24\). Row: the pattern is either BGBGBGBG or GBGBGBGB (2 ways); then the boys fill their 4 places in \(4!\) ways and the girls theirs in \(4!\) ways: \(2\times4!\times4!=1152\).

4. In how many ways can a committee of 3 be chosen from 20 people? In how many ways can a president, a secretary and a treasurer be chosen?

A committee is an unordered set: \(\binom{20}3=1140\). The three offices are different, so order matters: \(P^{20}_3=20\cdot19\cdot18=6840\).

5. You walk into a party without knowing anyone there. There are six women and four men and you know there are four married couples. In how many ways can you guess who the couples are? What if you know there are exactly three couples?

Four couples: choose which 4 of the 6 women are married, \(\binom64\), then match them with the 4 men, \(4!\): \(\binom64\,4!=15\times24=360\). Three couples: choose 3 of the 6 women and 3 of the 4 men, then match them: \(\binom63\binom43\,3!=20\times4\times6=480\).

6. Four shoes are taken at random from five different pairs. What is the probability that there is at least one pair among them?

All cases: \(\binom{10}4=210\) equally likely sets of 4 shoes. Count the sets with no pair."At least one pair" could mean one pair or two; "no pair" is a single clean case, and the complement gives the rest. Count them by the number \(k\) of left shoes: choose \(k\) left shoes from the 5 pairs, \(\binom5k\), then \(4-k\) right shoes from the \(5-k\) pairs not yet used, \(\binom{5-k}{4-k}\):

\[ \begin{aligned} &\tbinom50\tbinom54+\tbinom51\tbinom43+\tbinom52\tbinom32\\ &\quad+\tbinom53\tbinom21+\tbinom54\tbinom10\\ &=5+20+30+20+5=80. \end{aligned} \]

(Quicker: choose 4 of the 5 pairs and one shoe from each, \(\binom54\,2^4=80\).) So

\[ P(\text{at least one pair})=1-\frac{80}{210}=\frac{13}{21}. \]

You can now: tell the four urn cases apart by asking "put back?" and "order matters?"; compute \(n^r\), \(P^n_r\) and \(\binom nr\); and use \(\binom nr=\binom n{n-r}\) and the complement to shorten a count.

3Groups and repeated choices ~5 min

What is this? (identical objects)

Line up 4 balls in 4 slots: two black, two white. If you swap the two black balls, the row looks exactly the same. So counting as if every ball had its own name over-counts: each visible pattern appears once for every swap inside a colour group. Divide those swaps out.

(IV) Permutations of balls distinguishable by groups

Suppose we have 4 balls, two black and two white. There are 6 distinguishable arrangements:

●●○○   ●○●○   ●○○●   ○●●○   ○●○●   ○○●●

If the 4 balls were all distinguishable there would be \(4!\) ways to order them. But the two black balls cannot be told apart, so each arrangement has been counted \(2!\) times (once for each order of the black balls): we "undo" this by dividing by \(2!\). Similarly we divide by \(2!\) for the white balls:

\[ \frac{4!}{2!\,2!}=\frac{24}{4}=6. \]

In general, if we have \(n\) balls, \(m_1\) of colour number 1, \(m_2\) of colour number 2, and so on up to colour \(\ell\), where the colours are distinguishable but balls of the same colour are not, then

\[ \begin{aligned} &\text{number of distinguishable}\\ &\text{arrangements of the } n \text{ balls}\\ &\qquad=\frac{n!}{m_1!\,m_2!\cdots m_\ell!}, \end{aligned} \]

where of course \(n=m_1+m_2+\cdots+m_\ell\).

In words: arrange everything as if all were different (\(n!\)), then divide by the number of ways to shuffle each group of identical objects among themselves.

Reading the formula
\(n!\)
orders of the \(n\) slots if every ball had its own name.
\(m_1!\)
swaps of the colour-1 balls among their own slots; each swap leaves the row looking the same.
\(m_1!\,m_2!\cdots m_\ell!\)
all the invisible swaps together; dividing leaves one count per visible row.
Example

How many different "words" can be made from the letters of MISSISSIPPI? There are 11 letters: M once, I four times, S four times, P twice. So \(\dfrac{11!}{1!\,4!\,4!\,2!}=34\,650\).

With two colours the formula is a binomial coefficient: \(\dfrac{n!}{m!\,(n-m)!}=\binom nm\), because an arrangement is decided by choosing which \(m\) of the \(n\) places get colour 1.

What is this? (repeats without order)

Buying drinks from a shop with unlimited stock: you may take the same kind more than once, and only the final bag matters, not the order you picked things up. A bag is fully described by a shopping list of counts (how many of each kind). So counting bags means counting shopping lists.

(V) Sampling with replacement and without ordering

We understand the situation as follows.

  • The \(n\) distinguishable balls can be considered as \(n\) different types of objects.
  • Sampling with replacement means that each type has an unlimited supply.

Using the "\(*\) and \(|\)" method (explained below), one can show that

\[ \begin{aligned} &\text{number of ways to choose}\\ &r\text{ objects from } n\text{ types}=\binom{r+n-1}{n-1}. \end{aligned} \]

More exercises of this type are in the tutorial.

In words: an unordered sample with repeats is decided by how many of each type you take; count those lists of numbers with stars and bars.

Going further: the "\(*\) and \(|\)" method

An unordered sample of \(r\) objects from \(n\) types is fully described by the counts \(x_1,\dots,x_n\ge0\) of each type, with \(x_1+\cdots+x_n=r\). Write \(x_1\) stars, then a bar, then \(x_2\) stars, a bar, and so on: \(r\) stars and \(n-1\) bars in a row of \(r+n-1\) symbols. For example, with \(n=3\) types and \(r=4\):

∗∗ | | ∗∗  means  \(x_1=2,\ x_2=0,\ x_3=2\).

Every row of symbols gives exactly one sample and every sample gives exactly one row. A row is decided by choosing which \(n-1\) of the \(r+n-1\) places hold bars: \(\binom{r+n-1}{n-1}\) ways. (Equivalently \(\binom{r+n-1}{r}\), by Exercise 2.2.)

Example. Buy 4 drinks from 3 kinds: \(\binom{4+3-1}{3-1}=\binom62=15\) different orders.

You can now: count arrangements with repeated letters or colours by dividing out the identical swaps; count unordered samples with replacement by stars and bars; and pick the right one of the four cases from the table.

4Stirling's formula ~3 min

What is this?

\(n!\) is a long product of \(n\) numbers of very different sizes. Stirling replaces it by one number raised to the power \(n\), which logarithms (or a calculator) handle in one step. The "typical" factor, in the multiplicative sense, is about \(n/e\), and a small correction \(\sqrt{2\pi n}\) fixes the rest.

Factorials grow extremely fast (\(20!\approx2.4\times10^{18}\)), and without a calculator you cannot multiply them out. Stirling's formula gives a good approximation.

Stirling's formula

For large values of \(n\),

\[ n!\approx\sqrt{2\pi n}\left(\frac ne\right)^n. \]

In words: \(n!\) is roughly \(n^n e^{-n}\) times a correction \(\sqrt{2\pi n}\). The ratio of the two sides tends to 1 as \(n\to\infty\) (the difference does not go to 0).

Reading the formula
\(\left(\frac ne\right)^n\)
the main part: \(n\) factors, each replaced by the typical size \(n/e\) (their geometric mean is close to \(n/e\) for large \(n\)).
\(\sqrt{2\pi n}\)
a slowly growing correction factor.
\(\approx\)
the ratio of the two sides tends to 1: the relative error shrinks, even though the difference grows.

You may think the right-hand side is uglier than \(n!\), but it is easier to compute, because powers are easy to compute (with logarithms). Thus, if \(n\) is large,

\[ \begin{aligned} \binom{2n}n=\frac{(2n)!}{n!\,n!}&\approx\frac{\sqrt{4\pi n}\,\left(\frac{2n}e\right)^{2n}}{2\pi n\left(\frac ne\right)^{2n}}\\ &=\frac{2^{2n}}{\sqrt{n\pi}}. \end{aligned} \]

Check of the last step:

\[ \left(\frac{2n}e\right)^{2n}\Big/\left(\frac ne\right)^{2n}=2^{2n}, \]

and

\[ \begin{aligned} \sqrt{4\pi n}/(2\pi n)&=2\sqrt{\pi n}/(2\pi n)\\ &=1/\sqrt{\pi n}. \end{aligned} \]
Example

When \(n=50\), the exact value is

\[ \binom{100}{50}\left(\frac12\right)^{100}=0.0795892374\ldots \]

while the approximation gives

\[ \begin{aligned} \frac{2^{100}}{\sqrt{50\pi}}\cdot\frac1{2^{100}}&=\frac1{\sqrt{50\pi}}\\ &=0.0797884561\ldots \end{aligned} \]

The relative error is about \(0.25\%\). (This number is the probability of exactly 50 heads in 100 tosses of a fair coin: there are \(\binom{100}{50}\) favourable sequences out of \(2^{100}\).)

Stirling's formula can be used to establish a special case of the Central Limit Theorem (Theorem 2.46, section 18), but the details are left to a more advanced probability course.

How good is Stirling's formula?

The curve is the ratio \(\sqrt{2\pi n}(n/e)^n\,/\,n!\) for \(n=1\) to 60. It starts at 0.92 and climbs towards 1: the relative error is roughly \(1/(12n)\).

You can now: approximate \(n!\) and \(\binom{2n}n\) for large \(n\) with Stirling's formula; and say that its accuracy is about the ratio, not the difference.

5A short history of probability ~7 min

What is this?

De Méré's mistake was to add chances of events that can happen together. The repair Pascal and Fermat used is still the standard trick for "at least one": find the chance that it never happens, and take that away from 1.

This section is optional. It is not examined as such, but the dice problem is a good exercise in the complement rule.

F. N. David (Games, Gods and Gambling, Harner Publishing, 1962) describes how, with the advent of Christianity the concept of the random event of the pagan philosophers was rejected. According to St. Augustine (354–430), nothing happened by chance; everything was minutely controlled by the will of God. If events appear to occur at random, that is because of the ignorance of man and not in the nature of the events. Man's true endeavour was to discover and submit himself to the Divine Will, and not to cloud this search by looking at patterns of behaviour in aggregates of events.

The contents and applications of probability theory owe their origin to a question about a gambling game, raised by Antoine Gombaud, the Chevalier de Méré (1607–1684), about throwing a die. He sent the problem to Blaise Pascal, who shared it with Pierre de Fermat; de Méré is famous as the gambler whose questions started the Pascal–Fermat correspondence.

The dice problem

Two gambling games were popular at the time. Game (1): bet on rolling at least one "6" in four throws of a fair die. De Méré argued: the chance of a "6" in one throw is \(\frac16\), so in four throws it is \(\frac16\cdot4=\frac23\). (This is incorrect, but he didn't know.) He bet on this game and made a considerable amount of money.

Game (2), believed to be equivalent: bet on at least one double "6" in 24 throws of two fair dice. The reasoning: a double "6" in one throw has chance \(\frac1{36}\), so in 24 throws it is \(\frac{24}{36}=\frac23\), the same as (the incorrect) game (1). But he was losing money in game (2). In 1654 he challenged Pascal, who shared the problem with Fermat. Their answer works with the complement (the chance of the event not happening):

(1) The chance of not rolling a "6" in four independent throws of a fair die is

\[ \frac56\cdot\frac56\cdot\frac56\cdot\frac56=\frac{625}{1296}, \]

so the chance of at least one "6" in four throws is

\[ 1-\frac{625}{1296}=\frac{671}{1296}=0.5177\gt0.5. \]

This explains why de Méré made a good amount of money with double odds on his bet (he won slightly more often than he lost).

(2) The chance of not rolling a double "6" in one throw of a pair of fair dice is \(1-\frac1{36}=\frac{35}{36}\). The chance of none in 24 independent throws is \(\left(\frac{35}{36}\right)^{24}\), so the chance of at least one double "6" in 24 throws is

\[ 1-\left(\frac{35}{36}\right)^{24}=0.4914\lt0.5. \]

This explains why de Méré was losing in this game.

Why "\(\frac16\times4\)" is wrong

Adding probabilities is only allowed for events that cannot happen together (section 6, Axiom (iv)). "A 6 on throw 1" and "a 6 on throw 2" can both happen, so adding counts those outcomes twice. Pushed further, the wrong argument would give "\(\frac76\)" for seven throws, which is impossible. For "at least one", use \(1-P(\text{none})\).

Christiaan Huygens (a teacher of Leibniz) learned of the incident and in 1657 published the first book on probability, De Ratiociniis in Ludo Aleae (The Value of all Chances in Games of Fortune), a study of gambling problems. Probability developed rapidly in the 18th century, with major contributions by Jakob Bernoulli (1655–1705) and Abraham de Moivre (1667–1754). In 1812 P.-S. Laplace (1749–1827) introduced new ideas and techniques in his book Théorie Analytique des Probabilités and applied them to mathematical statistics, actuarial mathematics and statistical mechanics. Many others later contributed, including the Russian school: Chebyshev, Markov and Kolmogorov.

One of the main difficulties in "mathematising" probability was its definition; the search for a generally accepted definition took nearly 300 years. It was resolved in the 20th century by treating probability on an axiomatic basis: a monograph by the Russian mathematician A. Kolmogorov (1933) introduced the axiomatic approach that is the foundation of modern probability (English translation: Foundations of Probability Theory, Chelsea, New York, 1950). Since then probability has become part of a more general discipline, measure theory (HKU course MATH7505).

You can now: compute "at least one" probabilities as \(1-P(\text{none})\); and explain why adding \(\frac16\) four times is wrong.

6Sample spaces, events and the axioms ~8 min

What is this?

Picture the sample space as a map of every outcome that could happen, and an event as a region you shade on that map. Then imagine exactly one bucket of sand, total amount 1, spread over the map. The probability of an event is how much sand lies in its region.

The axioms just say what any sensible way of spreading the sand must obey: no region has negative sand or more than the whole bucket; the whole map holds all of it; and sand in regions that do not overlap adds up. This sand picture runs through the rest of the chapter.

This section sets up the basic concepts of probability theory. In daily life we often meet uncertainty: toss a fair coin and the result could be a head (\(H\)) or a tail (\(T\)); you can never predict the exact outcome. Throw a fair die and you may get 1, 2, 3, 4, 5 or 6 dots. Each such action is called an experiment, and each of its possible outcomes (or collections of outcomes) an event.

Definition 2.5: experiment

An experiment is a process that generates well-defined outcomes, but the outcomes cannot be predicted with certainty. In any single repetition of the experiment, one and only one of the possible outcomes will occur.

Definition 2.6: sample space

A sample space \(\Omega\) is the set of all possible experimental outcomes. Any particular outcome is called a sample point, an element of the sample space, written \(\omega\).

  • The sample space of tossing a coin is \(\{H,T\}\).
  • The sample space of throwing a die is \(\{1,2,3,4,5,6\}\).

In words: \(\Omega\) (capital omega) is the list of everything that can happen; \(\omega\) (small omega) is one thing that can happen.

Definition 2.7: event

An event is a collection of one or more of the outcomes of an experiment, that is, a subset of the sample space. An event that includes only one outcome is called a simple event.

In words: an event is a "yes or no" question about the outcome, recorded as the set of outcomes for which the answer is yes.

Examples

The following can be regarded as sample spaces: (a) a bushel of apples; (b) all the oxygen molecules in a given container; (c) all the students in HKU. (Pick one at random: the sample points are the apples, molecules or students.)

Two dice (Dec 2023 Q6(b)): \(\Omega=\{(i,j): i,j=1,\dots,6\}\), 36 ordered pairs. The event "the sum is greater than 10" is \(A=\{(5,6),(6,5),(6,6)\}\).

Infinitely many coin tosses (May 2026 Q7(j); see also section 18): an outcome is an infinite sequence of heads and tails, so \[ \begin{aligned} \Omega=\{&(\omega_1,\omega_2,\omega_3,\dots):\\ &\omega_i\in\{H,T\}\text{ for every } i\}. \end{aligned} \] This \(\Omega\) is uncountable.

A probability \(P\) is a numerical measure of the likelihood ("how likely?") that a specific event of \(\Omega\) will happen. It is also called a probability measure on the sample space \(\Omega\). The axiomatic approach for defining \(P\) follows Kolmogorov.

Set notation used from now on: \(A\cup B\) ("\(A\) or \(B\)", union), \(A\cap B\) ("\(A\) and \(B\)", intersection), \(A'=\Omega\setminus A\) ("not \(A\)", complement), \(\emptyset\) (the empty event, which never happens), \(A\subset B\) ("\(A\) is inside \(B\)": if \(A\) happens then \(B\) happens), \(A\setminus B=A\cap B'\) ("\(A\) but not \(B\)").

Axioms of Probability

Let \(\mathcal F\) be a set containing the events of an experiment, that is, subsets of the sample space \(\Omega\), and let \(P:\mathcal F\to\mathbb R\) assign to each event \(A\) a number \(P(A)\), called the probability of \(A\), such that the following axioms hold:

  1. (a) \(\Omega\in\mathcal F\);
    (b) \(A\in\mathcal F\Rightarrow A':=\Omega\setminus A\in\mathcal F\);
    (c) \[ \begin{aligned} &A_1,A_2,A_3,\dots\in\mathcal F\\ &\Rightarrow A_1\cup A_2\cup A_3\cup\cdots\in\mathcal F. \end{aligned} \]
  2. \(0\le P(A)\le1\).
  3. \(P(\Omega)=1\).
  4. If \(A_1,A_2,A_3,\dots\) are events such that \(A_i\cap A_j=\emptyset\) for all \(i\ne j\), then \[ \begin{aligned} &P(A_1\cup A_2\cup A_3\cup\cdots)\\ &\quad=P(A_1)+P(A_2)+P(A_3)+\cdots \end{aligned} \]

In words: (i) the events form a family that contains "anything happens", and is closed under "not" and under "or" (even infinitely many); (ii) probabilities lie between 0 and 1; (iii) something certainly happens; (iv) for events that cannot happen together, the probability that one of them happens is the sum of their probabilities.

Reading the formula
(i)
the regions you are allowed to weigh: the whole map, the outside of any allowed region, and any combination of allowed regions.
(ii) \(0\le P(A)\le1\)
no region holds negative sand or more than the whole bucket.
(iii) \(P(\Omega)=1\)
the whole map holds all the sand: something certainly happens.
(iv) \(A_i\cap A_j=\emptyset\)
the regions do not overlap, so no grain is counted twice.
(iv) sum
then the sand in the combined region is the sum of the sand in the pieces, even for infinitely many pieces.

"State the Axioms of Probability" is a recurring exam part (Dec 2023, Dec 2024, May 2025). Learn the four axioms as written above, including the condition \(A_i\cap A_j=\emptyset\) for \(i\ne j\) in (iv).

We might have hoped to simplify \(\mathcal F\) to the set of all subsets of \(\Omega\), written \(2^\Omega\) (as in the tutorial) or \(\mathcal P(\Omega)\) in some texts. However, unexpected difficulties arise if we do so when \(\Omega\) is uncountable (studied in MATH7505). In contrast, if \(\Omega\) is finite or countably infinite (its points can be listed as \(\omega_1,\omega_2,\dots\)), then no such trouble can arise and we may assign a probability to each and every subset: \(\mathcal F=2^\Omega\).

Axiom (iv) implies \(P(\emptyset)=0\) (Proposition 2.11 below), and so, taking \(A_{n+1}=A_{n+2}=\cdots=\emptyset\), for any finite collection of events \(A_1,\dots,A_n\),

\[ \begin{aligned} &P(A_1\cup A_2\cup\cdots\cup A_n)\\ &\quad=P(A_1)+P(A_2)+\cdots+P(A_n), \end{aligned} \]

provided that the events are mutually exclusive (or disjoint): \(A_i\cap A_j=\emptyset\) for all \(i\ne j\).

You can now: write down a sample space and an event as a set; state the four Axioms of Probability word for word, including \(A_i\cap A_j=\emptyset\) in (iv); and say why \(\mathcal F\) can be all subsets when \(\Omega\) is finite or countable.

7Classical probability and first rules ~9 min

What is this?

When all outcomes are equally likely, the sand is spread evenly: every outcome gets the same pinch. Then the sand in a region is just (number of outcomes in it) × (one pinch), and probability becomes counting. That is why sections 1 to 3 came first.

Classical probability

A classical statement of probability: the probability of an event is the ratio of the number of cases favourable to that event to the total number of cases, provided that all these are equally likely.

In our language: the sample space is a finite set of possible cases, \(\Omega=\{\omega_1,\omega_2,\dots,\omega_n\}\), each \(\omega_i\) being a "case". An event \(A\) is a subset \(\{\omega_{i_1},\omega_{i_2},\dots,\omega_{i_m}\}\), each \(\omega_{i_j}\) being a "favourable case". The probability of \(A\) is then the ratio

\[ \begin{aligned} P(A)&=\frac{|A|}{|\Omega|}=\frac mn\\ &=\frac{\#\text{ favourable cases}}{\#\text{ all possible cases}}. \end{aligned} \]

One can check that this \(P\) does fulfil the Axioms of Probability.

In words: when all outcomes are equally likely, probability is counting: favourable over total. \(|A|\) means the number of elements of \(A\).

Check of the axioms: \(0\le m\le n\) gives (ii); \(|\Omega|/|\Omega|=1\) gives (iii); and if \(A\), \(B\) are disjoint, \(|A\cup B|=|A|+|B|\) gives (iv) (a finite \(\Omega\) has only finitely many different events).

Probability as frequency. If a fair coin is tossed a number of times, how likely will a head appear? Common sense suggests \(P(\text{Head})\approx\dfrac{\#\text{Heads}}{n}\), where \(n\) is the number of times the coin is flipped. If you flip a fair coin 1000 times, do you expect exactly 500 heads? Not likely. But if we flip it a sufficiently large number of times, then \(\dfrac{\#\text{Heads}}{n}\to\dfrac12\). This idea of repeated independent trials with an identical coin giving the limiting frequency \(\frac12\) is a result of the Law of Large Numbers (section 18), which justifies the intuitive foundation of probability as frequency.

Example 2.8

If six dice are rolled, what is the probability that all show different faces?

Answer. The ordered results \((d_1,\dots,d_6)\) are equally likely: \(6^6\) cases (case (I) of section 2). Favourable: the six faces are 1 to 6 in some order, \(6!\) cases (case (II)). HenceSix dice are six slots; "all different" means no face may be reused, so the options go 6, 5, 4, 3, 2, 1.

\[ \frac{6!}{6^6}=\frac{720}{46656}=0.015432. \]
Exercise 2.9

A die is rolled three times. What is the probability that you get a larger number each time?

Solution. \(6^3=216\) equally likely ordered results. A strictly increasing triple \(a\lt b\lt c\) is fixed by the set \(\{a,b,c\}\) of three different faces (there is exactly one increasing order), so there are \(\binom63=20\) favourable cases. The probability is \(\dfrac{20}{216}=\dfrac5{54}\).

Below are some important properties of a general probability \(P\) (not only the classical one), as direct consequences of the axioms. First, if events \(A\) and \(B\) cannot occur in the same trial, we say:

Definition 2.10

Two events \(A\), \(B\) are mutually exclusive or disjoint if \(A\cap B=\emptyset\).

Proposition 2.11

(a) \(P(\emptyset)=0\).
(b) For any event \(A\), \(P(A')=1-P(A)\).
(c) If \(A\subset B\) are events, then \(P(A)\le P(B)\).

In words: the impossible event has probability 0; "not \(A\)" has the rest of the probability; a bigger event is at least as likely.

Proof. (a) Let all \(A_i=\emptyset\) in Axiom (iv) (they are disjoint): \(P(\emptyset)=P(\emptyset)+P(\emptyset)+P(\emptyset)+\cdots\). A number equal to an infinite sum of copies of itself can only be 0, so \(P(\emptyset)=0\).

(b) Since \(A\cup A'=\Omega\) and \(A\cap A'=\emptyset\), Axioms (iii) and (iv) give \(1=P(\Omega)=P(A\cup A')=P(A)+P(A')\).

(c) When \(A\subset B\), \(B=A\cup(A'\cap B)\), and \(A\), \(A'\cap B\) are disjoint. Hence by Axiom (iv), \(P(B)=P(A)+P(A'\cap B)\), which is \(\ge P(A)\) by Axiom (ii).

What is this? (inclusion–exclusion)

Shade \(A\) and shade \(B\) on the map. If you weigh the sand in \(A\) and then the sand in \(B\), the sand in the overlap has been weighed twice. Take it off once and each grain in \(A\cup B\) is counted exactly once.

Proposition 2.12: the inclusion–exclusion principle

If \(A\) and \(B\) are two events, then

\[ P(A\cup B)=P(A)+P(B)-P(A\cap B). \]

In words: adding \(P(A)\) and \(P(B)\) counts the overlap \(A\cap B\) twice, so subtract it once.

Reading the formula
\(P(A)+P(B)\)
sand in \(A\) plus sand in \(B\): the lens in the middle is counted twice.
\(-P(A\cap B)\)
take one copy of the lens away.
\(P(A\cup B)\)
every grain in either region, each counted once.

Proof. Write \(A\cup B=A\cup(A'\cap B)\) and note that \(A\) and \(A'\cap B\) are disjoint. By Axiom (iv),

\[ P(A\cup B)=P(A)+P(A'\cap B). \]

Similarly \(B=(A\cap B)\cup(A'\cap B)\), and \(A\cap B\), \(A'\cap B\) are disjoint. By Axiom (iv) again,

\[ P(B)=P(A\cap B)+P(A'\cap B). \]

Subtract the second equation from the first to eliminate \(P(A'\cap B)\).

Inclusion–exclusion: the overlap is counted twice

\(P(A)+P(B)\) covers the middle lens twice. The three pieces \(A\cap B'\), \(A\cap B\), \(A'\cap B\) are disjoint, which is how the proof uses Axiom (iv).

Exercise 2.13

If \(A,B,C\) are any three events, show that

\[ \begin{aligned} &P(A\cup B\cup C)\\ &=P(A)+P(B)+P(C)\\ &\quad-P(A\cap B)-P(A\cap C)\\ &\quad-P(B\cap C)+P(A\cap B\cap C). \end{aligned} \]

Solution. Apply Proposition 2.12 to the two events \(A\cup B\) and \(C\):

\[ \begin{aligned} P(A\cup B\cup C)&=P(A\cup B)+P(C)\\ &\quad-P((A\cup B)\cap C). \end{aligned} \]

Now \(P(A\cup B)=P(A)+P(B)-P(A\cap B)\), and \((A\cup B)\cap C=(A\cap C)\cup(B\cap C)\), so by Proposition 2.12 again

\[ \begin{aligned} &P((A\cup B)\cap C)\\ &=P(A\cap C)+P(B\cap C)\\ &\quad-P(A\cap B\cap C), \end{aligned} \]

because \((A\cap C)\cap(B\cap C)=A\cap B\cap C\). Substituting both gives the result.

Exercise 2.14

Prove that for any two events \(A\) and \(B\), \(P(A\cup B)\ge P(A)+P(B)-1\). Can you give a concrete example of this inequality?

Solution. By Proposition 2.12, \(P(A\cap B)=P(A)+P(B)-P(A\cup B)\). Since \(P(A\cup B)\le1\) (Axiom (ii)),

\[ P(A\cap B)\ge P(A)+P(B)-1. \]

And since \(A\cap B\subset A\cup B\), Proposition 2.11(c) gives \[ \begin{aligned} P(A\cup B)&\ge P(A\cap B)\\ &\ge P(A)+P(B)-1, \end{aligned} \] the inequality asked for.

Example. 90% of students pass Paper 1 and 85% pass Paper 2. Then at least \(0.9+0.85-1=75\%\) pass both. With \(P(A)=P(B)=\frac12\) the bound gives 0: two events of probability \(\frac12\) can be disjoint (a head and a tail on the same toss).

The inequality for \(P(A\cup B)\) is true but weak (\(P(A\cup B)\ge P(A)\) already says at least as much). The useful one is Bonferroni's inequality \(P(A\cap B)\ge P(A)+P(B)-1\). Both are proved above.

Exercise 2.15

We have \(A\cap A=A\), but when is \(P(A)\cdot P(A)=P(A)\)? Can \(P(A)=0\) but \(A\ne\emptyset\)?

Solution. \(P(A)^2=P(A)\) means \(P(A)(P(A)-1)=0\): exactly when \(P(A)=0\) or \(P(A)=1\). (By section 10, these are the events that are independent of themselves.)

Yes, \(P(A)=0\) is possible with \(A\ne\emptyset\). 8Conditional probability ~5 min

What is this?

You are told that \(B\) happened. Every outcome outside \(B\) is now impossible, so cross it out: the world shrinks to \(B\). The chance of \(A\) is now the share of \(B\)'s sand that also lies in \(A\).

Dividing by \(P(B)\) rescales the sand left in the smaller world so that it adds up to 1 again. This only makes sense if \(B\) had some sand to begin with, which is why \(P(B)\gt0\) is required.

This section and the next lead to the theorem of Bayes. In certain situations, knowing additional information about an event can change the probability of its occurrence. For example, the likelihood of an earthquake happening today may be low, but if we know that one occurred yesterday, this likelihood increases significantly.

Definition 2.16: conditional probability

Let \(A\), \(B\) be two events. The conditional probability of \(A\) given that \(B\) has already occurred, written \(P(A\mid B)\), is

\[ P(A\mid B)=\frac{P(A\cap B)}{P(B)}. \]

Here we impose the proviso that \(P(B)\ne0\), that is, \(P(B)\gt0\).

In words: once we know \(B\) happened, \(B\) becomes the whole world. Of \(B\)'s probability, the share that also lies in \(A\) is the new probability of \(A\).

Reading the formula
\(B\)
the new, smaller world: only outcomes where \(B\) happened are left.
\(P(A\cap B)\)
the part of \(A\) that survives the shrinking.
\(\div P(B)\)
rescales so that the new world holds total probability 1.
\(P(B)\gt0\)
a world with no probability in it cannot be rescaled.

Multiplied out, the definition gives the multiplication rule \(P(A\cap B)=P(A\mid B)\,P(B)\), used constantly in tree diagrams.

Example

Pick a number at random from \(\{1,2,3,\dots,10\}\). Let \(A\) be the event that the number is prime: \(A=\{2,3,5,7\}\), \(P(A)=\frac4{10}\). Let \(B\) be the event that it is odd: \(B=\{1,3,5,7,9\}\), \(P(B)=\frac5{10}\). Given that an odd number is picked, the probability that it is prime changes:

\[ \begin{aligned} P(A\mid B)=\frac{P(A\cap B)}{P(B)}&=\frac{3/10}{5/10}\\ &=\frac35=\frac6{10}, \end{aligned} \]

since \(A\cap B=\{3,5,7\}\). Knowing "odd" raises the chance of "prime" from 0.4 to 0.6.

Example 2.17

A perfect die is thrown twice. Given that the total obtained is 7, what is the probability that the first point obtained is \(k\), \(1\le k\le6\)?

Answer. The required probability is

\[ \begin{aligned} &P(\text{1st point is }k\mid\text{total is }7)\\ &\quad=\frac{P(\text{1st point is }k\text{ and the total is }7)}{P(\text{total is }7)}. \end{aligned} \]

The event "1st point is \(k\) and the total is 7" is \(\{(k,7-k)\}\), one of the 36 equally likely outcomes, whileThe world shrinks to the 6 cells with total 7, all still equally likely, and exactly one of them starts with \(k\).

\[ \begin{aligned} &\text{“total is 7”}\\ &=\{(1,6),(2,5),(3,4),\\ &\qquad(4,3),(5,2),(6,1)\}. \end{aligned} \]

Hence

\[ P(\text{1st point is }k\mid\text{total is }7)=\frac{1/36}{6/36}=\frac16. \]

Conditioning on two dice (Example 2.17)

Rows: first throw; columns: second throw. Shaded cells form the condition \(B\); outlined cells form \(A\) = "first point is \(k\)". \(P(A\mid B)\) = (cells in both) / (cells in \(B\)). For total 7 every \(k\) gives \(\frac16\); for other totals it does not.

What is this? (conditioning gives a new probability)

After shrinking to \(B\) and rescaling, you have a complete new world with exactly 1 unit of sand in it. So everything that was true of probabilities in the old world (between 0 and 1, the whole world gets 1, non-overlapping pieces add) is true again inside \(B\).

Proposition 2.18

Let \(A\), \(A_i\), \(B\) be events (with \(P(B)\gt0\)). Then

(a) \(0\le P(A\mid B)\le1\);
(b) \(P(\Omega\mid B)=1\);
(c) whenever \(A_i\cap A_j=\emptyset\) for \(i\ne j\),

\[ \begin{aligned} &P(A_1\cup A_2\cup A_3\cup\cdots\mid B)\\ &=P(A_1\mid B)+P(A_2\mid B)\\ &\quad+P(A_3\mid B)+\cdots \end{aligned} \]

Proof of (a) and (b). (a) \(A\cap B\subset B\), so \(0\le P(A\cap B)\le P(B)\) by Axiom (ii) and Proposition 2.11(c); divide by \(P(B)\gt0\). (b)

\[ \begin{aligned} P(\Omega\mid B)&=P(\Omega\cap B)/P(B)\\ &=P(B)/P(B)=1. \end{aligned} \]

Proof of (c). By definition,

\[ \begin{aligned} &P(A_1\cup A_2\cup\cdots\mid B)\\ &\quad=\frac{P((A_1\cup A_2\cup\cdots)\cap B)}{P(B)}. \end{aligned} \]

As

\[ \begin{aligned} &(A_1\cup A_2\cup\cdots)\cap B\\ &\quad=(A_1\cap B)\cup(A_2\cap B)\cup\cdots, \end{aligned} \]

and \(A_i\cap A_j=\emptyset\) implies \((A_i\cap B)\cap(A_j\cap B)=\emptyset\), Axiom (iv) gives

\[ \begin{aligned} &P((A_1\cap B)\cup(A_2\cap B)\cup\cdots)\\ &\quad=P(A_1\cap B)+P(A_2\cap B)+\cdots \end{aligned} \]

Dividing each term by \(P(B)\) gives the right-hand side required.

Remark. This result, together with the Axioms of Probability, says that for any given event \(B\) with \(P(B)\gt0\), the new function \(Q:=P(\cdot\mid B)\), \(Q:\mathcal F\to\mathbb R\), is a probability measure on \(\Omega\). So every rule proved for \(P\) also holds for \(P(\cdot\mid B)\), for example \(P(A'\mid B)=1-P(A\mid B)\).

Trap

\(P(A\mid B)\) and \(P(B\mid A)\) are different numbers in general. In the example above, \(P(\text{prime}\mid\text{odd})=\frac35\) but \(P(\text{odd}\mid\text{prime})=\frac34\). And \(P(A'\mid B)=1-P(A\mid B)\) is true, but \(P(A\mid B')=1-P(A\mid B)\) is false in general.

You can now: compute \(P(A\mid B)\) from the definition or by counting inside \(B\); use \(P(A\cap B)=P(A\mid B)P(B)\); apply every rule of probability inside a conditional; and avoid swapping \(P(A\mid B)\) with \(P(B\mid A)\).

9Total probability and Bayes's theorem ~8 min

What is this?

Picture a test result as the end of a tree of branches. The first split is the hidden cause (which machine made the product, or whether a patient has the illness), with its probability before any evidence. The second split is the result (defective or not, test positive or not), with its chance under each cause. Following the tree forwards is easy: multiply along each path.

Bayes runs the tree backwards. You see the end of a path ("the test came back positive") and ask which first branch it came from. Collect every path that ends in that result; the share of their total probability that went through cause \(i\) is the new probability of cause \(i\). The causes must not overlap and must cover everything, so that every path starts on exactly one first branch.

Proposition 2.19: Bayes's theorem

Suppose that \(B_1,B_2,\dots,B_n\) are \(n\) mutually exclusive events whose union is the entire sample space \(\Omega\). Then for any event \(A\) (with \(P(A)\gt0\)) and any \(i\),

\[ P(B_i\mid A)=\frac{P(A\mid B_i)P(B_i)}{\displaystyle\sum_{j=1}^{n}P(A\mid B_j)P(B_j)}. \]

Written out, the denominator is \(P(A\mid B_1)P(B_1)+\cdots+P(A\mid B_n)P(B_n)\).

In words: to turn "probability of the evidence \(A\) given each cause \(B_i\)" round into "probability of cause \(B_i\) given the evidence", weight each cause by its prior probability and take cause \(i\)'s share of the total.

Reading the formula
\(P(B_i)\)
the prior: the first branch of the tree, how likely cause \(i\) is before you see any evidence.
\(P(A\mid B_i)\)
the second branch: how likely the evidence is if cause \(i\) is the truth.
\(P(A\mid B_i)P(B_i)\)
the probability of the whole path "cause \(i\), then evidence".
\(\sum_j P(A\mid B_j)P(B_j)\)
all paths that end in the evidence added together: this is \(P(A)\).
the fraction
the share of the evidence that came through cause \(i\): reasoning backwards from the result to the cause.
the partition condition
causes that do not overlap and cover \(\Omega\), so every path starts on exactly one first branch and none is missed.

Proof. Since \(\Omega=B_1\cup B_2\cup\cdots\cup B_n\),

\[ \begin{aligned} A=A\cap\Omega&=A\cap(B_1\cup\cdots\cup B_n)\\ &=(A\cap B_1)\cup\cdots\cup(A\cap B_n). \end{aligned} \]

Since \(B_i\cap B_j=\emptyset\) for \(i\ne j\), also \((A\cap B_i)\cap(A\cap B_j)=\emptyset\). Thus, by Axiom (iv),

\[ \begin{aligned} P(A)&=P(A\cap B_1)+P(A\cap B_2)\\ &\quad+\cdots+P(A\cap B_n). \end{aligned} \]

Using the definition, \(P(A\mid B_i)=\dfrac{P(A\cap B_i)}{P(B_i)}\), that is,

\[ P(A\cap B_i)=P(A\mid B_i)P(B_i). \]

Therefore

\[ P(B_i\mid A)=\frac{P(B_i\cap A)}{P(A)}=\frac{P(A\cap B_i)}{P(A)}. \]

Now plug the new expressions for \(P(A)\) and \(P(A\cap B_i)\) into this equation.

What is this? (total probability)

Run the tree forwards. Every way for the evidence \(A\) to happen goes through exactly one cause, so the chance of \(A\) is the sum over the paths that end in \(A\): (chance of the cause) × (chance of \(A\) under that cause).

Law of total probability (inside the proof) \[ \begin{aligned} P(A)&=P(A\mid B_1)P(B_1)\\ &\quad+\cdots+P(A\mid B_n)P(B_n). \end{aligned} \]

In words: split the world into the cases \(B_1,\dots,B_n\); the chance of \(A\) is the average of its chance in each case, weighted by how likely each case is. This is the denominator of Bayes's formula, and is often asked on its own.

A collection \(B_1,\dots,B_n\) of mutually exclusive events whose union is \(\Omega\) is called a partition of \(\Omega\): exactly one of them happens. The simplest partition is \(B,\ B'\): then \(P(A)=P(A\mid B)P(B)+P(A\mid B')P(B')\).

Example: three machines

In a manufacturing plant, three machines \(B_1,B_2,B_3\) produce 50%, 30% and 20% of the products. From past experience, 1%, 2% and 3% of the products made by each machine, respectively, are defective. A finished product is randomly selected. What is the probability that it is defective? And if a product is chosen at random and found to be defective, what is the probability that it was made by machine \(B_3\)?

Answer. Define the events \(A\) = the product is defective, and \(B_i\) = the product is made by machine \(B_i\).The machines are the first branches of the tree (the hidden cause); "defective" is the result we observe at the end of a path. It is given that \(P(B_1)=0.5\), \(P(B_2)=0.3\), \(P(B_3)=0.2\); \(P(A\mid B_1)=0.01\), \(P(A\mid B_2)=0.02\), \(P(A\mid B_3)=0.03\). By the law of total probability,

\[ \begin{aligned} P(A)&=0.01(0.5)+0.02(0.3)+0.03(0.2)\\ &=0.005+0.006+0.006=0.017. \end{aligned} \]

By Bayes's theorem,Working backwards: of all the probability that ends in "defective" (0.017), the path through machine 3 carries 0.006.

\[ \begin{aligned} P(B_3\mid A)&=\frac{P(A\mid B_3)P(B_3)}{P(A)}\\ &=\frac{0.03\cdot0.2}{0.017}=\frac{0.006}{0.017}=\frac6{17}. \end{aligned} \]

Since \(P(A)=0.017\ne P(A\mid B_1)=0.01\), the events \(A\), \(B_1\) are not independent (section 10). Similarly \(A,B_2\) are not independent, nor are \(A,B_3\).

Bayes's theorem as areas (machines example)

Each column's width is the share of production \(P(B_i)\) (50%, 30%, 20%); the coloured part of the column is the defective share \(P(A\mid B_i)\) (drawn 10 times taller so you can see it). The coloured area is \(P(A\cap B_i)\); the total coloured area is \(P(A)\), and \(P(B_i\mid A)\) is column \(i\)'s share of the coloured area.

Exercise 2.22

The family dog is missing after the picnic. Three hypotheses are suggested: (A) it has gone home; (B) it is still worrying that big bone in the picnic area; (C) it has wandered off into the woods. The a priori probabilities, assessed from the habits of the dog, are \(\frac14,\frac12,\frac14\). A child each is sent back to the picnic ground and to the edge of the woods to look for the dog. If it is in the former area, it is a cinch (90%) that it will be found; if it is in the latter, the chance is only a toss-up (50%). What is the probability that the dog will be found in the park?

Solution. Let \(F\) = the dog is found. The hypotheses partition \(\Omega\), with \(P(F\mid A)=0\) (nobody searches at home), \(P(F\mid B)=0.9\), \(P(F\mid C)=0.5\). By total probability,

\[ \begin{aligned} P(F)&=0\cdot\tfrac14+0.9\cdot\tfrac12+0.5\cdot\tfrac14\\ &=0.45+0.125=0.575=\tfrac{23}{40}. \end{aligned} \]

(Bayes then tells us, for example, that if the dog is not found, the chance it went home rises to \(P(A\mid F')=\frac{1\cdot\frac14}{1-0.575}=\frac{0.25}{0.425}=\frac{10}{17}\).)

Exercise 2.23

Urn one contains 2 black and 3 red balls; urn two contains 3 black and 2 red balls. We toss an unbiased coin to decide which urn to draw from, but we do not know which is which. Suppose the first ball drawn is black and it is put back; what is the probability that the second ball drawn from the same urn is also black?

Solution. Let \(U_1,U_2\) be the urn chosen (\(P=\frac12\) each) and \(K_1,K_2\) "first/second ball black". Given the urn, the two draws (with replacement) are independent. First,

\[ P(K_1)=\tfrac12\cdot\tfrac25+\tfrac12\cdot\tfrac35=\tfrac12. \]

\[ \begin{aligned} P(K_1\cap K_2)&=\tfrac12\left(\tfrac25\right)^2+\tfrac12\left(\tfrac35\right)^2\\ &=\tfrac12\cdot\tfrac{13}{25}=\tfrac{13}{50}. \end{aligned} \]

So \(P(K_2\mid K_1)=\dfrac{13/50}{1/2}=\dfrac{13}{25}=0.52\).

Another way: after a black first ball, Bayes updates the urn probabilities to \(P(U_1\mid K_1)=\frac{(1/2)(2/5)}{1/2}=\frac25\) and \(P(U_2\mid K_1)=\frac35\); then \(P(K_2\mid K_1)=\frac25\cdot\frac25+\frac35\cdot\frac35=\frac{13}{25}\). 10Independent events ~4 min

What is this?

Two events are independent when learning that one happened tells you nothing about the other. Toss two separate coins: being told the first came up heads leaves the second at \(\frac12\).

In the shrinking picture of section 8: shrink the world to \(B\). If \(A\) takes up the same share of the smaller world as it did of the whole world, then \(B\) carried no news about \(A\). Mutually exclusive events are the opposite: hearing that \(B\) happened tells you for certain that \(A\) did not.

Definition 2.20: independence

Two events \(A\), \(B\) are independent under \(P\) if

\[ P(A\cap B)=P(A)P(B). \]
  • Events \(A\), \(B\) (with non-zero probability) are independent under \(P\) if and only if \(P(A\mid B)=P(A)\), or equivalently \(P(B\mid A)=P(B)\). This means that the occurrence of event \(B\) has no effect on the probability of event \(A\), and vice versa.
  • Note the difference between the concepts of mutually exclusive events and independent events.

In words: independent means "knowing one tells you nothing about the other"; test it with the product rule.

Reading the formula
\(P(A\mid B)\)
\(A\)'s share of the shrunken world \(B\).
\(P(A)\)
\(A\)'s share of the whole world.
\(P(A\cap B)=P(A)P(B)\)
divide by \(P(B)\gt0\) and it says the two shares are equal: \(B\) tells you nothing about \(A\).
why the product form
it still makes sense when \(P(B)=0\), and it treats \(A\) and \(B\) the same way, so it is the definition.

Why the "if and only if": if \(P(B)\gt0\), then

\[ \begin{aligned} &P(A\mid B)=P(A)\\ &\iff P(A\cap B)/P(B)=P(A)\\ &\iff P(A\cap B)=P(A)P(B). \end{aligned} \]

What is needed is non-zero probability, not just a non-empty event (Exercise 2.15 shows these differ).

Mutually exclusive is not independent

If \(A\cap B=\emptyset\), then \(P(A\cap B)=0\). If also \(P(A)\gt0\) and \(P(B)\gt0\), then \(P(A)P(B)\gt0\ne P(A\cap B)\): the events are dependent. Indeed, knowing \(B\) happened tells you \(A\) did not happen. Example: one toss of a coin, \(A\) = head, \(B\) = tail.

What is this? (three events)

With three events, "no news" must hold for every combination: being told \(B\), or \(C\), or both \(B\) and \(C\), must leave the chance of \(A\) unchanged (and the same for the others). Checking the pairs alone is not enough, which is why the triple product is also required.

Mutual independence of three events (used in Exercise 2.21)

\(A,B,C\) are mutually independent if each pair is independent, \(P(A\cap B)=P(A)P(B)\), \(P(A\cap C)=P(A)P(C)\), \(P(B\cap C)=P(B)P(C)\), and \(P(A\cap B\cap C)=P(A)P(B)P(C)\).

Exercise 2.21

Show that if \(A,B,C\) are mutually independent events, then \(A\) and \(B\cup C\) are independent, and \(A\setminus B\) and \(C\) are independent.

Solution. First, \(A\cap(B\cup C)=(A\cap B)\cup(A\cap C)\), and the intersection of these two is \(A\cap B\cap C\). By inclusion–exclusion and independence,

\[ \begin{aligned} &P(A\cap(B\cup C))\\ &=P(A\cap B)+P(A\cap C)\\ &\quad-P(A\cap B\cap C)\\ &=P(A)\big[P(B)+P(C)-P(B)P(C)\big]\\ &=P(A)\big[P(B)+P(C)-P(B\cap C)\big]\\ &=P(A)P(B\cup C). \end{aligned} \]

Second, \(A\setminus B=A\cap B'\). Since \(A\cap C\) is the disjoint union of \(A\cap B'\cap C\) and \(A\cap B\cap C\),

\[ \begin{aligned} &P((A\cap B')\cap C)\\ &=P(A\cap C)-P(A\cap B\cap C)\\ &=P(A)P(C)-P(A)P(B)P(C)\\ &=P(A)(1-P(B))\,P(C). \end{aligned} \]

In the same way

\[ \begin{aligned} P(A\cap B')&=P(A)-P(A\cap B)\\ &=P(A)(1-P(B)). \end{aligned} \]

So \(P((A\setminus B)\cap C)=P(A\setminus B)P(C)\).

Going further: complements of independent events

If \(A\), \(B\) are independent, so are \(A'\) and \(B'\) (and \(A\), \(B'\)). Proof:

\[ \begin{aligned} &P(A'\cap B')=1-P(A\cup B)\\ &=1-P(A)-P(B)+P(A)P(B)\\ &=(1-P(A))(1-P(B))\\ &=P(A')P(B'). \end{aligned} \]

This is asked as a true/false statement in past papers (May 2019), and it is how "at least one" problems such as de Méré's are done: \(P(\text{at least one})=1-P(A_1')P(A_2')\cdots\).

Also, \(A\setminus B\) means \(A\cap B'\), so for independent \(A,B\): \(P(A\setminus B)=P(A)P(B')\) (Dec 2022 Q6(a)).

You can now: test two events for independence with the product rule; explain why disjoint events with positive probabilities are dependent; use that complements of independent events are independent; and check mutual independence of three events.

11Random variables and their pmf ~7 min

What is this?

A random variable puts a number tag on every outcome: each person in a population carries an age tag, each pair of dice carries a "total" tag. Nothing about the tag is random; the randomness is only in which outcome you get. Questions like "is the age between 20 and 40?" become events: the set of outcomes whose tag passes the test.

What is a random variable? The points of a sample space may be very concrete objects such as apples, molecules and people, and as such they have various qualities, some of which can be measured. An apple has its weight and volume; its juicy content can be measured, and even its taste may be graded by expert tasters. A molecule has mass and velocity, from which we can compute its momentum and kinetic energy. A human being has physiological characteristics such as age, height and weight, and many other numbers attached to him or her: I.Q., number of years of schooling, number of brothers and sisters, annual income earned and taxes paid, and so on.

Example: a population

Let \(\Omega\) be a human population of \(n\) individuals, labelled \(\Omega=\{\text{human}_1,\dots,\text{human}_n\}\). If we are interested in their age distribution, let \(\mathit{Age}(\omega)\) be the age of human \(\omega\). To each \(\omega\in\Omega\) is attached a number \(\mathit{Age}(\omega)\) in some unit, such as years. So the mapping \(\omega\mapsto\mathit{Age}(\omega)\) is a function with domain \(\Omega\). Similarly height, weight and income are functions \(\omega\mapsto\mathit{Height}(\omega)\), \(\omega\mapsto\mathit{Weight}(\omega)\), \(\omega\mapsto\mathit{Income}(\omega)\). (In the last case income may take negative values!)

For medical purposes a combination of height and weight may be an appropriate measure:

\[ \omega\mapsto\frac{\mathit{Weight}(\omega)}{\mathit{Height}^2(\omega)}, \]

which is the random variable BMI (body-mass index).

Convenient symbolism: the set of humans \(\omega\) in \(\Omega\) whose age is between 20 and 40 is written \(\{\omega\mid 20\le\mathit{Age}(\omega)\le40\}\), or more briefly \(\{20\le\mathit{Age}\le40\}\) when there is no danger of misunderstanding.

Definition 2.24: random variable

A numerically valued function \(X:\Omega\to\mathbb R\) is called a random variable (on \(\Omega\)).

In words: a random variable is a rule that attaches a number to every outcome of the experiment. It is not "random" in itself; the randomness is in which \(\omega\) occurs.

The \(\mathit{Age}\) above is a random variable. If \(\Omega\) is countable, then all subsets have a probability, so we may simply write

\[ \begin{aligned} &P(20\le\mathit{Age}\le40)\\ &\quad=P(\{\omega\mid20\le\mathit{Age}(\omega)\le40\}). \end{aligned} \]

Similarly, if \(I\) is a subset of \(\mathbb R\), \(P(\mathit{Age}\in I)=P(\{\omega\mid\mathit{Age}(\omega)\in I\})\), and so \(P(\mathit{Age}=20)=P(\{\omega\mid\mathit{Age}(\omega)=20\})\).

Following the convention, we write \(\{X=x\}=\{\omega\in\Omega\mid X(\omega)=x\}\). If this set has a probability we write it \(P(X=x)\) and call it "the probability that \(X\) takes (or assumes) the value \(x\)". The number \(x\) is called a realisation of \(X\). Capital letters (\(X\)) are random variables; small letters (\(x\)) are ordinary numbers.

What is this? (pmf)

Collect all the sand of the outcomes that carry the same tag \(x\) into one pile at the point \(x\) of the number line. The pmf lists the size of each pile. The piles hold all the sand, so they add up to 1.

Probability mass function (name used in exams)

For a random variable \(X\) with countably many values \(x_1,x_2,\dots\) (a discrete random variable), the list of probabilities \(p(x)=P(X=x)\) is its probability distribution or probability mass function (pmf). It satisfies \(p(x)\ge0\) and \(\sum_x p(x)=1\), and for any set \(I\) of numbers, \(P(X\in I)=\sum_{x\in I}p(x)\).

What is this? (distribution function)

Walk along the number line from the far left and keep a running total of the sand piles you have passed, including the one you are standing on. That running total is \(F_X(x)\). It starts at 0, climbs by a jump at each pile and ends at 1.

Definition 2.25: distribution function

The distribution function of \(X\), \(F_X:\mathbb R\to\mathbb R\), is

\[ F_X(x)=P(X\le x). \]

Its value at \(x\) "picks up" all the probabilities of values of \(X\) up to \(x\) (inclusive); for this reason the adjective "cumulative" is sometimes added to its name (cumulative distribution function, cdf).

In words: \(F_X(x)\) is the probability that \(X\) comes out at most \(x\). It rises from 0 (far left) to 1 (far right) and never goes down.

For a discrete \(X\), \(F_X\) is a step function: flat between the values of \(X\), jumping up by \(P(X=x)\) at each value \(x\). At a jump, \(F_X\) takes the upper value (because of the "\(\le\)"), so in a sketch the left end of each step is a filled dot and the right end an open dot. Useful facts: \(P(a\lt X\le b)=F_X(b)-F_X(a)\), and \(P(X\gt x)=1-F_X(x)\).

The distribution function of a discrete random variable

Filled dots: the value of \(F\) at a jump (the upper one). Open dots: the limit from the left. Move \(x\) to see \(F(x)=P(X\le x)\) pick up the probabilities at or to the left of \(x\).

You can now: describe a random variable as a function on \(\Omega\); read probabilities like \(P(1\le X\le2)\) from a pmf table; and sketch the step-shaped distribution function, with filled dots on the upper values.

12Expectation and functions of random variables ~9 min

What is this?

Put a weight of size \(P(X=x)\) at each position \(x\) on a light ruler. The point where the ruler balances is \(E(X)\). It is also the long-run average: repeat the experiment many times and the average of the values you see settles near the balance point (section 18).

Definition 2.26: expectation

For a random variable \(X\) defined on a countable sample space \(\Omega\), its mathematical expectation is the number

\[ E(X)=\sum_{\omega\in\Omega}X(\omega)\,P(\{\omega\}), \]

provided that \(\sum_{\omega\in\Omega}|X(\omega)|\,P(\{\omega\})\lt\infty\). \(E(X)\) is also called the expected value or the mean of \(X\), sometimes written \(\mu\) or \(\mu_X\). Grouping the \(\omega\) with the same value of \(X\), one can rewrite it as

\[ E(X)=\sum_x x\cdot P(X=x), \]

the weighted average of \(X\).

In words: multiply each possible value by its probability and add. It is the long-run average of \(X\) over many repetitions.

Reading the formula
\(x\)
the position of one weight on the ruler.
\(P(X=x)\)
the size of that weight.
\(\sum_x x\,P(X=x)\)
position × weight, added up: the balance point. The weights add up to 1, so there is no need to divide by the total weight.
the condition \(\sum|X(\omega)|P(\{\omega\})\lt\infty\)
with infinitely many weights, they must not sit so far out that the ruler has no balance point.

The condition "\(\sum|X(\omega)|P(\{\omega\})\lt\infty\)" only matters when \(X\) has infinitely many values: it makes sure the infinite sum has a definite finite value whatever order it is added in. For finitely many values it always holds.

Example

Find the expected number of heads in tossing a fair coin twice.

Answer. \(\Omega=\{(H,H),(H,T),(T,H),(T,T)\}\), each outcome with probability \(\frac14\). Let \(X\) be the number of heads. Then

\[ \begin{aligned} P(X=2)&=P(\{(H,H)\})=\tfrac14,\\ P(X=1)&=P(\{(H,T),(T,H)\})=\tfrac12,\\ P(X=0)&=P(\{(T,T)\})=\tfrac14. \end{aligned} \]

Hence \(E(X)=0\cdot\frac14+1\cdot\frac12+2\cdot\frac14=1\).

If the experiment "toss the fair coin twice" is performed \(N\) times (\(N\) big), one expects to see about \(E(X)\cdot N=N\) heads in total.

New random variables from old

Starting with some random variables, we can make new ones by operating on them; examples have already appeared (BMI).

Proposition 2.27

If \(X\) and \(Y\) are random variables, then so are \(X+Y\), \(X-Y\), \(XY\), \(X/Y\) (where \(Y\ne0\)), and \(aX+bY\) where \(a\) and \(b\) are two numbers.

Proof (an easy exercise). This is immediate from the definition: for example \(X+Y:\omega\mapsto X(\omega)+Y(\omega)\) is a function on \(\Omega\), just like \(X\) and \(Y\). The situation is exactly as in calculus: if \(f\) and \(g\) are functions, so are \(f+g\), \(f-g\), \(fg\), \(f/g\) (\(g\ne0\)), \(af+bg\). The only difference is that in calculus these are functions of \(x\), a real number, while here they are functions of \(\omega\), a sample point.

Proposition 2.29

If \(X\) and \(Y\) are random variables and \(g\) is a function of two (ordinary) variables, then \(g(X,Y)\), defined by \(\omega\mapsto g(X(\omega),Y(\omega))\), is also a random variable. (Easy exercise, as for Proposition 2.27.) For example, \(X^2\), \(XY\), \(X^2+Y^2\), \(e^{XY}\) are such.

What is this? (averaging a function of X)

To average \(g(X)\), keep every weight where its sand came from but read a new label on it: weight \(P(X=x)\) now carries the value \(g(x)\). You never need to rebuild the piles for \(g(X)\). Moving every value by the rule \(ax+b\) moves the balance point by the same rule.

Expectation of a function of \(X\)

The formula for \(E(X)\) contains a formula for the expectation of any function of \(X\):

\[ \begin{aligned} E(g(X))&=\sum_{\omega\in\Omega}g(X(\omega))P(\{\omega\})\\ &=\sum_x g(x)\,P(X=x). \end{aligned} \]

In words: to average \(g(X)\), apply \(g\) to each value of \(X\) but keep \(X\)'s probabilities. You do not need the distribution of \(g(X)\) first.

Linearity of expectation (follows from the expectation of a function of \(X\); see also Proposition 2.40) \[ E(aX+b)=aE(X)+b. \]

Proof:

\[ \begin{aligned} &\sum_x(ax+b)P(X=x)\\ &=a\sum_x xP(X=x)+b\sum_xP(X=x)\\ &=aE(X)+b\cdot1. \end{aligned} \]

In words: scaling and shifting the values scales and shifts the average. But in general \(E(g(X))\ne g(E(X))\): for example \(E(X^2)\ne(E(X))^2\) (section 17).

You can now: compute \(E(X)\) and \(E(g(X))\) from a pmf; use \(E(aX+b)=aE(X)+b\) as a shortcut; build new random variables from old ones; and remember that \(E(X^2)\ne(E(X))^2\) in general.

13Random variables with densities ~7 min

What is this?

Now the sand is not in piles but spread continuously along the number line, thicker in some places and thinner in others. The density \(f(u)\) is how thick the sand is at \(u\): sand per unit length. The probability of landing between \(a\) and \(b\) is the amount of sand over that stretch, which is the area under \(f\). A thickness can be more than 1 when the sand is piled on a short stretch; only the total amount must be 1.

When a sample space is uncountable (for example all real numbers in an interval), there is a technical "measurability" issue: it is impossible to assign a probability to every subset of it. The issue is resolved by confining ourselves to sets belonging to an adequate class called a Borel field (MATH3603), which is the \(\mathcal F\) in the Axioms of Probability. Without going into this more advanced mathematics, we take up a particular but very important situation that covers most applications and needs little abstraction: random variables with a density.

Definition 2.32: density function

A function \(f:\mathbb R\to\mathbb R\) satisfying the two conditions

(i) \(f(u)\ge0\) for all \(u\),   (ii) \(\displaystyle\int_{-\infty}^{\infty}f(u)\,du=1\)

is called a density function on \(\mathbb R\).

A random variable is still a function \(X:\Omega\to\mathbb R\), \(\omega\mapsto X(\omega)\), but its probabilities are prescribed by a density function \(f\), so that for any interval \([a,b]\)

\[ P(a\le X\le b)=\int_a^b f(u)\,du. \]

Such a random variable is said to have a density, the function \(f\).

In words: probability is area under the density curve. The total area is 1; the area over \([a,b]\) is the chance that \(X\) lands in \([a,b]\). The value \(f(u)\) itself is not a probability (it can be bigger than 1).

Reading the formula
\(f(u)\ge0\)
sand cannot be negatively thick.
\(\int_{-\infty}^{\infty}f(u)\,du=1\)
all the sand on the whole line adds up to one bucket.
\(f(u)\,du\)
thickness × a tiny length: the sand on a tiny stretch at \(u\).
\(\int_a^b\)
add the tiny stretches from \(a\) to \(b\): the sand, and so the probability, over \([a,b]\).
Example

Consider \(f(u)=3u^2\) if \(0\le u\le1\), and \(f(u)=0\) otherwise. Is it the density function of some random variable \(X\)? What is \(P(X\ge0.5)\) then?

Answer. \(f(u)\ge0\) for all \(u\). Next,

\[ \int_{-\infty}^{\infty}f(u)\,du=\int_0^13u^2\,du=\Big[u^3\Big]_0^1=1. \]

So both conditions hold and \(f\) is a density function of some \(X\). Then

\[ \begin{aligned} P(X\ge0.5)&=\int_{0.5}^{\infty}f(u)\,du\\ &=\int_{0.5}^13u^2\,du\\ &=\Big[u^3\Big]_{0.5}^1\\ &=1-0.125=0.875. \end{aligned} \]

(The integral from 0.5 to \(\infty\) only picks up \([0.5,1]\), since \(f=0\) beyond 1.)

Probability as area under a density

The shaded area is \(P(a\le X\le b)=\int_a^bf(u)\,du=F(b)-F(a)\). Default: the example above, \(P(X\ge0.5)=0.875\). Note that \(3u^2\) reaches height 3: a density can exceed 1.

Intermezzo: integration by substitution

The idea is to reverse the chain rule, \(\dfrac{d}{dx}f(g(x))=f'(g(x))\cdot g'(x)\). If you let \(u=g(x)\) (grouping complicated terms and calling them \(u\)) and use \(du=g'(x)\,dx\), then

\[ \begin{aligned} \int f'(g(x))\,g'(x)\,dx&=\int f'(u)\,du\\ &=f(u)+C\\ &=f(g(x))+C. \end{aligned} \]

For the definite version:

\[ \begin{aligned} \int_a^bf'(g(x))\,g'(x)\,dx&=\int_{g(a)}^{g(b)}f'(u)\,du\\ &=f(g(b))-f(g(a)). \end{aligned} \]

In words: change variable, change \(dx\) to \(du\), and change the limits to the new variable's values. This is the substitution rule of HKDSE M2.

14Distribution function and expectation with densities ~8 min

What is this?

\(F(x)\) is the running total of sand to the left of \(x\). As you walk right, the running total grows fastest where the sand is thickest; that rate of growth is the density. So differentiating \(F\) gives \(f\), and integrating \(f\) gives \(F\). The expectation is still the balance point, now of a continuous spread of sand.

Distribution function with a density

The distribution function \(F\) of \(X\) is defined in the same way as before:

\[ \begin{aligned} F(x)=F_X(x)&:=P(X\le x)\\ &=\int_{-\infty}^xf(u)\,du. \end{aligned} \]

In words: \(F(x)\) is the area under the density to the left of \(x\).

Theorem 2.36: the First Fundamental Theorem of Calculus

Suppose \(f\) is continuous. Then

\[ \begin{aligned} F'(x)&=\frac{d}{dx}P(X\le x)\\ &=\frac{d}{dx}\int_{-\infty}^xf(u)\,du=f(x). \end{aligned} \]

(Proof omitted.) We use it to recover the density \(f\) from \(F\).

In words: differentiate the distribution function to get the density; integrate the density to get the distribution function.

Expectation with a density \[ E(X)=\int_{-\infty}^{\infty}u\,f(u)\,du, \] \[ E(g(X))=\int_{-\infty}^{\infty}g(u)\,f(u)\,du. \]

In words: the same weighted average as \(\sum x\,P(X=x)\), with the sum replaced by an integral and \(P(X=x)\) by \(f(u)\,du\). In particular \(E(X^n)=\int u^nf(u)\,du\), the \(n\)-th moment.

Reading the formula
\(u\)
a position on the line.
\(f(u)\,du\)
the sand on a tiny stretch at that position: the weight there.
\(\int u\,f(u)\,du\)
position × weight, added over the whole line: the balance point.
\(g(u)\)
for \(E(g(X))\): the same weights, but each read with the new label \(g(u)\).
FTC with the chain rule \[ \begin{aligned} &\frac{d}{dx}\int_{g(x)}^{h(x)}f(u)\,du\\ &=f(h(x))\,h'(x)-f(g(x))\,g'(x), \end{aligned} \]

which will be of use later (section 15).

In words: with variable limits, differentiate by plugging each limit into \(f\), times the derivative of that limit; upper limit plus, lower limit minus.

Why: if \(\Phi\) is an antiderivative of \(f\), the integral is \(\Phi(h(x))-\Phi(g(x))\); differentiate with the chain rule.

Example: lifetime of a light bulb

Let \(X\) be the lifetime in hours of a certain light bulb. Assume it follows the exponential distribution with parameter \(\lambda=1/1000\), with density \(f(u)=\frac1{1000}e^{-u/1000}\) if \(u\ge0\) and \(0\) if \(u\lt0\). Find the expected lifetime of this type of light bulb.

Answer. The required answer is

\[ \begin{aligned} E(X)&=\int_{-\infty}^\infty u f(u)\,du\\ &=\int_0^\infty\frac{u}{1000}e^{-u/1000}\,du. \end{aligned} \]

To solve this we need integration by parts.

Intermezzo: integration by parts, via LATE

Integration by parts reverses the product rule \((f\cdot g)'=f'\cdot g+f\cdot g'\):

\[ \begin{aligned} &\int(f(u)g(u))'\,du=f(u)g(u)+C\\ &=\int f'(u)g(u)\,du\\ &\quad+\int f(u)g'(u)\,du. \end{aligned} \]

So (with the \(u\) suppressed)

\[ \int f\cdot g'\,du=f\cdot g-\int f'\cdot g\,du, \]

or in the form of definite integrals

\[ \int_a^bf\cdot g'\,du=\Big[f\cdot g\Big]_a^b-\int_a^bf'\cdot g\,du. \]

The notation \(\big[f\cdot g\big]_a^b=f(b)g(b)-f(a)g(a)\) works for all \(a,b\), even when they are \(\infty\) or \(-\infty\) (read as a limit). This technique shows you how to "integrate" a product. The choice of \(f(u)\) (the factor you differentiate) in \(\int_a^bf\cdot g'\,du\) is made by the L-A-T-E hierarchy: take as \(f\) whichever comes first in

  • L: logarithmic functions
  • A: algebraic functions (including polynomials, \(\sqrt x\), \(x^{-2}\), etc.)
  • T: trigonometric functions
  • E: exponential functions

In words: differentiate the factor that gets simpler (a power of \(u\) goes down to a constant), integrate the factor that stays just as easy (an exponential).

Example, continued

In \(u\cdot\frac1{1000}e^{-u/1000}\), \(u\) is "A" in the hierarchy and takes precedence over the "E" factor. Set \(f(u)=u\) and \(g'(u)=\frac1{1000}e^{-u/1000}\); then \(f'(u)=1\) and \(g(u)=-e^{-u/1000}\). Hence

\[ \begin{aligned} &\int_0^\infty u\cdot\tfrac1{1000}e^{-u/1000}\,du\\ &=\Big[u\cdot\big(-e^{-u/1000}\big)\Big]_0^\infty+\int_0^\infty e^{-u/1000}\,du\\ &=0+\Big[-1000\,e^{-u/1000}\Big]_0^\infty=1000. \end{aligned} \]

The bracket is 0 at both ends: at \(u=0\) because of the factor \(u\), and as \(u\to\infty\) because \(ue^{-u/1000}\to0\) (an exponential beats any power). So the expected lifetime is 1000 hours; in general the exponential distribution with parameter \(\lambda\) has mean \(1/\lambda\).

Exercise 2.37

Let \(X\) be the duration of a distant call in minutes, with density \(f(u)=a\sqrt u\) if \(0\le u\le100\), and 0 elsewhere, where \(a\) is a constant. The cost per minute of a call is $5, with an additional $10 service charge. Find the expected cost \(5X+10\).

What is this? (one exact value has probability 0)

A single point has no width, so the sand lying exactly on it is zero, however thick the sand is there. Only stretches of positive length hold sand.

A fundamental difference

The two kinds of random variable are similar, but there is a fundamental difference. If \(X\) has a density, then

\[ \begin{aligned} P(X=x)&=P(x\le X\le x)\\ &=\int_x^xf(u)\,du=0. \end{aligned} \]

Geometrically, this is the trivial fact that a line segment has zero area. Since \(x\) is arbitrary, \(X\) takes any preassigned value with probability zero. This is in direct contrast to a random variable taking a countable set of values, which must take some of these values with positive probability. It seems paradoxical that on the one hand \(X(\omega)\) must be some number for every \(\omega\), and on the other hand any given number has probability zero.

Example: spinning a needle

Spin a needle on a circular dial. When it stops it points at a random angle \(\theta\) (measured from the horizontal, say). Under normal conditions it is reasonable to suppose that \(\theta\) is uniformly distributed between \(0^\circ\) and \(360^\circ\) (Exercise 2.35), with density \(f(u)=1/360\) if \(0\le u\le360\), and 0 otherwise. Thus for any \(\theta_1\lt\theta_2\) within the \(360^\circ\) range,

\[ \begin{aligned} P(\theta_1\le\theta\le\theta_2)&=\int_{\theta_1}^{\theta_2}\frac1{360}\,du\\ &=\frac{\theta_2-\theta_1}{360}. \end{aligned} \]

The probability of the needle pointing between any two directions is proportional to the angle between them. If the angle \(\theta_2-\theta_1\) shrinks to zero, so does the probability. Hence in the limit the probability of the needle pointing exactly at \(\theta\) is zero. From an empirical point of view this event does not really make sense, because the needle itself has a width. In the end it is the mathematical fiction of a "line without width" that is the root of the paradox.

Consequence: \(\le\) or \(\lt\) does not matter (with a density)

For \(X\) with a density,

\[ \begin{aligned} P(a\le X\le b)&=P(a\lt X\lt b)\\ &=P(a\le X\lt b)\\ &=F(b)-F(a). \end{aligned} \]

For a discrete \(X\) it matters a lot: \(P(X\le1)\) and \(P(X\lt1)\) differ by \(P(X=1)\).

15The density of a transformed variable ~7 min

What is this?

If \(Y=g(X)\), every value of \(X\) is moved to a new place and its sand moves with it. Tracking the thickness directly is hard, but tracking the running total is easy: the sand that ends up to the left of \(y\) is the sand that started in the region of \(X\) values sent there. Find that region, write the running total, then differentiate it to get the thickness.

If \(X\) has a density and \(Y=g(X)\), how do we find the density of \(Y\)? The method (the cdf method): first find the distribution function \(P(Y\le y)\) in terms of \(X\)'s probabilities, then differentiate.

Example 2.38

If \(X\) has density \(f\), find the density of (i) \(aX+b\), where \(a,b\) are constants; (ii) \(X^2\).

Answer (i). Let \(Y=aX+b\). For \(a\gt0\),

\[ \begin{aligned} P(Y\le y)&=P(aX+b\le y)\\ &=P\!\left(X\le\frac{y-b}a\right). \end{aligned} \]

Hence, by Theorem 2.36 and the chain rule,

\[ \begin{aligned} f_Y(y)&=\frac{d}{dy}P\!\left(X\le\frac{y-b}a\right)\\ &=f\!\left(\frac{y-b}a\right)\cdot\frac1a. \end{aligned} \]

Answer (ii). Let \(W=X^2\). For \(w\ge0\),Squaring sends both \(x\) and \(-x\) to the same place, so the sand left of \(w\) comes from a stretch on both sides of 0.

\[ \begin{aligned} P(W\le w)&=P(X^2\le w)\\ &=P(-\sqrt w\le X\le\sqrt w). \end{aligned} \]

(For \(w\lt0\), \(P(W\le w)=0\), so \(f_W(w)=0\).) Hence, by the FTC with the chain rule, for \(w\gt0\),

\[ \begin{aligned} f_W(w)&=\frac{d}{dw}P(-\sqrt w\le X\le\sqrt w)\\ &=\frac{d}{dw}\int_{-\sqrt w}^{\sqrt w}f(u)\,du\\ &=f(\sqrt w)\cdot\frac1{2\sqrt w}\\ &\quad-f(-\sqrt w)\cdot\left(\frac{-1}{2\sqrt w}\right)\\ &=\frac{f(\sqrt w)+f(-\sqrt w)}{2\sqrt w}. \end{aligned} \]

Dividing an inequality by \(a\) keeps its direction only when \(a\gt0\). For \(a\lt0\) the event is \(X\ge\frac{y-b}a\), so \(P(Y\le y)=1-F\big(\frac{y-b}a\big)\) and \(f_Y(y)=f\big(\frac{y-b}a\big)\cdot\big(-\frac1a\big)\). Both cases together: \(f_Y(y)=\dfrac1{|a|}f\!\left(\dfrac{y-b}a\right)\).

\(\dfrac{y-b}a\)

\(f\!\left(\dfrac{y-b}a\right)\)

\(\dfrac1{|a|}\)

Method: density of \(Y=g(X)\) (the cdf method)
  1. Do: Write \(F_Y(y)=P(Y\le y)=P(g(X)\le y)\) and turn the event into a statement about \(X\) (an interval, or two). Watch the direction of inequalities and the range of \(y\) (e.g. \(y\lt0\) for \(Y=X^2\) or \(|X|\)). The sand that lands left of \(y\) is the sand that started at these \(X\) values; a negative factor flips the line, and some \(y\) are never reached.
  2. Do: Express it with \(F_X\) or an integral of \(f\) with limits depending on \(y\). \(X\)'s density is the only sand you can measure directly.
  3. Do: Differentiate in \(y\) (chain rule, or the FTC with the chain rule from section 14) to get \(f_Y(y)\). State where \(f_Y=0\). The thickness of the sand is the rate at which the running total grows (Theorem 2.36).

Intermezzo: a summary

Before going on, here is a summary of the concepts of random variables:

  • A random variable \(X\) is just a function, \(X:\Omega\to\mathbb R\).
  • \(A=\{a\le X\le b\}\) is a subset of \(\Omega\), containing all elements of \(\Omega\) that are mapped by \(X\) to a real number between \(a\) and \(b\).
  • If \(\Omega\) is countable, the probabilities of \(X\) are computed via \(P\), e.g. \(P(a\le X\le b)=\sum_{x=a}^bP(X=x)\), \(E(X)=\sum_x x\cdot P(X=x)\). Some people call this a discrete random variable; this chapter simply calls it a random variable.
  • If \(\Omega\) is uncountable, we only study those random variables \(X\) that have a density function \(f\): \(P(a\le X\le b)=\int_a^bf(u)\,du\), \(E(X)=\int_{-\infty}^\infty uf(u)\,du\). Some people call this a continuous random variable; this chapter calls it a random variable with density \(f\).
  • What a random variable should be called is up to your preference. However, the distribution function of \(X\), in either case, is always \(F(x)=F_X(x)=P(X\le x)\), with the probability on the right computed by \(\sum\) or by \(\int\). Some people call \(F\) the cumulative distribution function (cdf) of \(X\), which is fine.
  • For the countable case, the probability \(P\) (that is, \(x\mapsto P(X=x)\)) is also called a probability distribution function. The shared use of the word "distribution" reflects the fact that \(F\) and \(P\) are equivalent notions in the countable case: each can be computed from the other.
Names in past papers

Past papers say "probability mass function (pmf)" for \(x\mapsto P(X=x)\) and "probability density function (pdf)" or "density" for \(f\). Some texts call the discrete \(P(X=x)\) a "probability distribution function (pdf)": be careful, in most books and in the exam "pdf" means the density. A density value \(f(x)\) is not \(P(X=x)\) (that is 0).

16Random vectors and independent random variables ~7 min

What is this?

With two random variables, every outcome carries two tags, so the sand is shared out over a grid: one row for each value of \(X\), one column for each value of \(Y\). Pour each row's sand into the right-hand margin and you get \(X\)'s own distribution; pour each column into the bottom margin and you get \(Y\)'s. Keeping just one column and rescaling it is conditioning again: the world shrinks to \(Y=y\).

For simplicity of notation we consider only two random variables \(X\) and \(Y\); the extension to any finite number is straightforward. We only consider the case where \(X\) and \(Y\) are countably valued.

Joint distribution

Let \(X\) take the values \(\{x_i\}\) and \(Y\) the values \(\{y_j\}\), and put

\[ P(X=x_i,\ Y=y_j)=p(x_i,y_j). \]

This gives the joint probability distribution of the random vector \((X,Y)\). (The comma means "and": \(\{X=x_i\}\cap\{Y=y_j\}\).)

In words: the joint distribution is a table: rows for the values of \(X\), columns for the values of \(Y\), each cell the probability of that pair. All cells add up to 1.

Marginal distributions

To get the distribution of \(X\) alone, let \(y_j\) range over all possible values:

\[ \begin{aligned} P(X=x_i)&=P(X=x_i,\ Y=\text{anything})\\ &=\sum_jp(x_i,y_j)=:p(x_i,*). \end{aligned} \]

The set of all \(p(x_i,*)\) gives the marginal distribution of \(X\). The marginal distribution of \(Y\), \(p(*,y_j)=\sum_ip(x_i,y_j)\), is defined similarly.

In words: add along each row of the table to get \(X\)'s distribution, down each column to get \(Y\)'s. They are written in the margins of the table, hence the name.

Expectation of a function of \((X,Y)\) \[ E(g(X,Y))=\sum_i\sum_jg(x_i,y_j)\,p(x_i,y_j). \]

This is just a rearrangement of the terms in the definition of the expectation of \(g(X,Y)\) as one random variable: \(E(g(X,Y))=\sum_\omega g(X(\omega),Y(\omega))P(\{\omega\})\).

In words: go through every cell of the table, apply \(g\) to that pair, multiply by the cell's probability, and add.

The case where \(X\) and \(Y\) are uncountably valued is omitted: it needs double integration \(\iint\) over a joint density, a concept from a more advanced calculus course.

Conditional distribution (used in past papers)

For a value \(y\) with \(P(Y=y)\gt0\), Definition 2.16 gives the conditional distribution of \(X\) given \(Y=y\):

\[ P(X=x\mid Y=y)=\frac{p(x,y)}{p(*,y)}. \]

In words: keep only the column \(Y=y\) of the table and rescale it so it adds up to 1.

What is this? (independent random variables)

\(X\) and \(Y\) are independent when being told the column (the value of \(Y\)) tells you nothing about the row (the value of \(X\)). Then inside every column, the rows share the sand in the same proportions as in the margin, which is the same as saying every cell equals (row total) × (column total).

Definition 2.39: independent random variables

The countably valued random variables \(X_1,\dots,X_n\) are independent if for any real numbers \(x_1,\dots,x_n\),

\[ \begin{aligned} &P(X_1=x_1,\dots,X_n=x_n)\\ &\quad=P(X_1=x_1)\cdots P(X_n=x_n). \end{aligned} \]

One can prove that \(X\), \(Y\) are independent if and only if

\[ P(X\le x,\ Y\le y)=P(X\le x)\,P(Y\le y) \]

for all \(x,y\in\mathbb R\).

In words: two random variables are independent when every cell of the joint table equals (row total) × (column total). To prove independence, check every cell; to disprove it, one failing cell is enough.

Reading the formula
\(P(X_1=x_1,\dots,X_n=x_n)\)
the sand in one cell of the joint table.
\(P(X_1=x_1)\cdots P(X_n=x_n)\)
the product of the matching margin totals.
"for any" \(x_1,\dots,x_n\)
every cell must pass, including cells with probability 0, where one of the margins must then be 0 too.
Example: a coin and a die

Toss a fair coin and a fair die simultaneously. Let \(X\) be the number of heads obtained and \(Y\) the number of dots obtained. Suppose \(P(X=i,Y=j)=\frac1{12}\) for all \(i,j\). Are \(X\) and \(Y\) independent?

Answer. \(X\) takes values \(\{0,1\}\) and \(Y\) takes values \(\{1,2,3,4,5,6\}\). For \(i=0,1\),

\[ \begin{aligned} P(X=i)&=P(X=i,Y=1)\\ &\quad+\cdots+P(X=i,Y=6)\\ &=6\cdot\tfrac1{12}=\tfrac12, \end{aligned} \]

and similarly \(P(Y=j)=2\cdot\frac1{12}=\frac16\) for all \(j=1,\dots,6\). Hence

\[ \begin{aligned} P(X=i,Y=j)&=\frac1{12}=\frac12\cdot\frac16\\ &=P(X=i)P(Y=j) \end{aligned} \]

for all \(i,j\). So \(X\) and \(Y\) are independent.

Independence check for a 2 × 2 joint table

\(X\) (rows) and \(Y\) (columns) take values 0 and 1; \(p(1,1)\) is whatever is left so the table adds up to 1. Each cell shows the joint probability and, below it, the product of its row and column totals. Default: Dec 2023 Q7(c). Try \(p(0,0)=0.08\), \(p(0,1)=0.12\), \(p(1,0)=0.32\).

Proposition 2.40

The following hold for random variables \(X\), \(Y\) in general:

(a) \(E(a)=a\) and \(E(aX)=aE(X)\) for any constant \(a\);
(b) \(E(aX+bY)=aE(X)+bE(Y)\) for any two constants \(a\) and \(b\); hence \(E(X+Y)=E(X)+E(Y)\);
(c) if \(X\) and \(Y\) are independent, then \(E(XY)=E(X)E(Y)\).

In words: expectation of a sum is the sum of expectations, always (independent or not). Expectation of a product is the product of expectations when the variables are independent.

Proof of (a) and (b) (countable case). (a) The constant \(a\) is the random variable \(\omega\mapsto a\), so \(E(a)=\sum_\omega aP(\{\omega\})=a\cdot1\); and \(E(aX)=\sum_\omega aX(\omega)P(\{\omega\})=aE(X)\). (b)

\[ \begin{aligned} &E(aX+bY)\\ &=\sum_\omega\big(aX(\omega)+bY(\omega)\big)P(\{\omega\})\\ &=aE(X)+bE(Y), \end{aligned} \]

splitting the sum.

Proof of (c) (countable case). For \(X,Y\) independent, \(P(X=x,Y=y)=P(X=x)P(Y=y)\) for all possible \(x,y\). So

\[ \begin{aligned} E(XY)&=\sum_{x,y}xy\,P(X=x,Y=y)\\ &=\sum_{x,y}xy\,P(X=x)P(Y=y)\\ &=\sum_xxP(X=x)\sum_yyP(Y=y)\\ &=E(X)E(Y). \end{aligned} \]
Trap

\(E(XY)=E(X)E(Y)\) does not prove independence. Example: \(X\) takes \(-1,0,1\) with probability \(\frac13\) each and \(Y=X^2\). Then \(E(XY)=E(X^3)=0=E(X)E(Y)\), but \(Y\) is a function of \(X\): \(P(X=0,Y=1)=0\ne\frac13\cdot\frac23\). Likewise, knowing the two marginal distributions does not decide the joint table (Dec 2022 Q6(d)).

You can now: read marginal and conditional distributions from a joint table; compute \(E(g(X,Y))\) cell by cell; decide whether \(X\) and \(Y\) are independent; and use \(E(aX+bY)=aE(X)+bE(Y)\) always and \(E(XY)=E(X)E(Y)\) only with independence.

17Variance ~8 min

What is this?

Go back to the ruler with weights, balancing at \(\mu\). If the weights all sit close to the balance point, the variable is predictable; if some sit far out, it is spread out. The variance is the average of the squared distances from the balance point. Squaring makes left and right both count, and makes far-out weights count more. The standard deviation takes the square root to get back to the units of \(X\).

The mean tells you where a random variable is centred; the variance tells you how spread out it is.

Definition 2.41: variance and standard deviation

Let \(X\) be a random variable. The variance of \(X\), written \(\operatorname{Var}(X)\), is \(E\big([X-E(X)]^2\big)\). For computation, let \(\mu=E(X)\). Then:

(i) Case I (\(X\) countably valued):

\[ \operatorname{Var}(X)=\sum_x(x-\mu)^2\cdot P(X=x). \]

(ii) Case II (\(X\) uncountably valued with density \(f\)):

\[ \operatorname{Var}(X)=\int_{-\infty}^{\infty}(u-\mu)^2f(u)\,du. \]

We also write \(\operatorname{Var}(X)=\sigma^2\), where \(\sigma=\sqrt{\operatorname{Var}(X)}\) is the standard deviation of \(X\), sometimes written \(\sigma_X\).

In words: the variance is the average squared distance of \(X\) from its mean; the standard deviation brings it back to the units of \(X\).

Reading the formula
\(x-\mu\)
how far the weight at \(x\) sits from the balance point.
\((x-\mu)^2\)
squared, so both sides count as positive and far-out weights count more.
\(\cdot P(X=x)\)
weighted by how much probability sits there (\(f(u)\,du\) with a density).
\(\sum\) or \(\int\)
added up: the average squared distance.
\(\sigma\)
the square root, back in the units of \(X\).

So what is the meaning of \(\sigma\)?

  • We want to understand the average deviation of \(X\) from its mean \(E(X)\), that is \(E(|X-E(X)|)\). This can be used, but it is difficult for computations (absolute values are awkward to integrate and differentiate).
  • So we consider the mean square deviation \(E(|X-E(X)|^2)\) instead.
  • \(\sigma\) is a "gauge" of the average deviation of a random variable (sample value) from its mean.
  • The smaller it is, the better the random variable clusters around its average, and the population is well centred or concentrated.
Example: the car park again

Recall the 24-hour car park, with distribution \(P(X=x)=0.1,0.1,0.2,0.2,0.3,0.1\) for \(x=0,1,2,3,4,5\). Then

\[ \begin{aligned} E(X)&=0(0.1)+1(0.1)+2(0.2)\\ &\quad+3(0.2)+4(0.3)+5(0.1)=2.8. \end{aligned} \]

So

\[ \begin{aligned} \operatorname{Var}(X)&=(0-2.8)^2(0.1)\\ &\quad+(1-2.8)^2(0.1)\\ &\quad+(2-2.8)^2(0.2)\\ &\quad+(3-2.8)^2(0.2)\\ &\quad+(4-2.8)^2(0.3)\\ &\quad+(5-2.8)^2(0.1)\\ &=0.784+0.324+0.128\\ &\quad+0.008+0.432+0.484\\ &=2.16. \end{aligned} \]

Check with Proposition 2.42 below:

\[ \begin{aligned} E(X^2)&=0+0.1+0.8+1.8\\ &\quad+4.8+2.5=10, \end{aligned} \]

so \(\operatorname{Var}(X)=10-2.8^2=10-7.84=2.16\). The standard deviation is \(\sigma=\sqrt{2.16}\approx1.47\) cars.

Proposition 2.42

If \(E(X^2)\lt\infty\), then so is \(E(|X|)\), and

\[ \operatorname{Var}(X)=E(X^2)-E(X)^2. \]

In words: variance = (mean of the square) − (square of the mean). This is the quick way to compute it.

Proof. \(X^2-2|X|+1=(|X|-1)^2\ge0\), so \(E(X^2-2|X|+1)\ge0\) and therefore \(E(X^2)+1\ge2E(|X|)\). This proves the first assertion. Next, with \(E(X)\) a constant,

\[ \begin{aligned} \operatorname{Var}(X)&=E\big([X-E(X)]^2\big)\\ &=E\big(X^2-2E(X)X+E(X)^2\big)\\ &=E(X^2)-2E(X)E(X)+E(X)^2\\ &=E(X^2)-E(X)^2. \end{aligned} \]
Proposition 2.43

If \(a\), \(b\) are constants, then

\[ \operatorname{Var}(aX+b)=a^2\operatorname{Var}(X). \]

In words: shifting by \(b\) does not change the spread; scaling by \(a\) multiplies the variance by \(a^2\) (and the standard deviation by \(|a|\)).Sliding the ruler moves the weights and the balance point together, so no distance changes; stretching by \(a\) stretches every distance by \(|a|\), and squared distances by \(a^2\).

Proof. By definition, using \(E(aX+b)=aE(X)+b\),

\[ \begin{aligned} &\operatorname{Var}(aX+b)\\ &=E\big([(aX+b)-E(aX+b)]^2\big)\\ &=E\big([aX+b-aE(X)-b]^2\big)\\ &=a^2E\big([X-E(X)]^2\big)\\ &=a^2\operatorname{Var}(X). \end{aligned} \]
Example: uniform on [0, 1]

Let \(X\) have the uniform density \(f(u)=1\) if \(0\le u\le1\), and 0 otherwise. Then

\[ E(X)=\int_0^1u\,du=\frac12, \] \[ E(X^2)=\int_0^1u^2\,du=\frac13. \]

Thus \(\operatorname{Var}(X)=E(X^2)-E(X)^2=\frac13-\frac14=\frac1{12}\). Hence

\[ E(2X+1)=2E(X)+1=2, \] \[ \operatorname{Var}(2X+1)=2^2\operatorname{Var}(X)=\frac4{12}=\frac13. \]
Proposition 2.44

If \(X\) and \(Y\) are independent and both have finite variances, then

\[ \operatorname{Var}(X+Y)=\operatorname{Var}(X)+\operatorname{Var}(Y). \]

Proof. Adding a constant to a random variable does not change its variance (Proposition 2.43 with \(a=1\)), so we may assume \(E(X)=E(Y)=0\) (replace \(X\) by \(X-E(X)\), which is still independent of \(Y-E(Y)\)). Then \(\operatorname{Var}(X)=E(X^2)\) and \(\operatorname{Var}(Y)=E(Y^2)\), and

\[ \begin{aligned} &\operatorname{Var}(X+Y)\\ &=E((X+Y)^2)-E(X+Y)^2\\ &=E(X^2+2XY+Y^2)\\ &=E(X^2)+E(Y^2)+2E(XY)\\ &=\operatorname{Var}(X)+\operatorname{Var}(Y)\\ &\quad+2E(X)E(Y). \end{aligned} \]

(using \(E(X+Y)=0\) and, by independence, Proposition 2.40(c)). The very last term, \(E(X)E(Y)\), is zero. Done.

Variance of a sum: independence needed

\(\operatorname{Var}(X+Y)=\operatorname{Var}(X)+\operatorname{Var}(Y)\) can fail for dependent variables: with \(Y=X\), \(\operatorname{Var}(2X)=4\operatorname{Var}(X)\), not \(2\operatorname{Var}(X)\). And \(\operatorname{Var}(X-Y)=\operatorname{Var}(X)+\operatorname{Var}(Y)\) for independent \(X,Y\) (a plus sign: \((-1)^2=1\)).

Exercise 2.45 (**Very Important**)

Let \(X_1,X_2,\dots\) be independent random variables with the same probability distribution, mean \(\mu\) and variance \(\sigma^2\). Define

\[ \bar X_n:=\frac{X_1+\cdots+X_n}n. \]

What are \(E(\bar X_n)\) and \(\operatorname{Var}(\bar X_n)\)? What happens when \(n\to\infty\)? Interpret the results.

Solution. By linearity (Proposition 2.40),

\[ \begin{aligned} E(\bar X_n)&=\frac1n\big(E(X_1)+\cdots+E(X_n)\big)\\ &=\frac{n\mu}n=\mu. \end{aligned} \]

By Proposition 2.43 (with \(a=\frac1n\)) and Proposition 2.44 (independence, applied repeatedly),Independent errors partly cancel when added, so the total spreads only like \(\sqrt n\,\sigma\), not \(n\sigma\); dividing by \(n\) then shrinks the spread.

\[ \begin{aligned} \operatorname{Var}(\bar X_n)&=\frac1{n^2}\operatorname{Var}(X_1+\cdots+X_n)\\ &=\frac1{n^2}\cdot n\sigma^2=\frac{\sigma^2}n. \end{aligned} \]

As \(n\to\infty\), \(E(\bar X_n)\) stays \(\mu\) while \(\operatorname{Var}(\bar X_n)\to0\). Interpretation: the average of many independent measurements is centred on the true mean, and its spread (standard deviation \(\sigma/\sqrt n\)) shrinks as \(n\) grows: averaging more data gives a more reliable estimate of \(\mu\). This is the idea behind the laws of large numbers (section 18) and behind estimation in Chapter P4.

Variance of a function

As \(E(g(X))\) is defined for a function of a random variable \(X\), \(\operatorname{Var}(g(X))\) is given by

\[ \operatorname{Var}(g(X))=E\Big(\big[g(X)-E(g(X))\big]^2\Big). \]

Even more generally,

\[ \begin{aligned} &\operatorname{Var}(g(X,Y))\\ &=E\Big(\big[g(X,Y)-E(g(X,Y))\big]^2\Big). \end{aligned} \]

In words: any quantity computed from random variables is a random variable, and its variance is its mean square deviation. In practice: \(\operatorname{Var}(g)=E(g^2)-E(g)^2\), with both expectations computed from the (joint) table.

Example: \(\operatorname{Var}(X+Y)\) from a joint table

When \(X\), \(Y\) are not independent, compute \(\operatorname{Var}(X+Y)\) with the variance of a function: \(E(X+Y)\) and \(E((X+Y)^2)\) from the table. Take \(p(0,0)=0.1\), \(p(0,1)=0.2\), \(p(1,0)=0.3\), so \(p(1,1)=0.4\) (Dec 2022 Q6(c)). \(X+Y\) is 0, 1, 1, 2 in the four cells:

\[ \begin{aligned} E(X+Y)&=0(0.1)+1(0.2+0.3)\\ &\quad+2(0.4)=1.3,\\ E((X+Y)^2)&=0+1(0.5)+4(0.4)\\ &=2.1, \end{aligned} \]

so \(\operatorname{Var}(X+Y)=2.1-1.3^2=0.41\). (Here

\[ \begin{aligned} &\operatorname{Var}(X)+\operatorname{Var}(Y)\\ &\quad=0.7\cdot0.3+0.6\cdot0.4\\ &\quad=0.45\ne0.41: \end{aligned} \]

\(X\), \(Y\) are dependent.)

You can now: compute \(\operatorname{Var}(X)\) from the definition or as \(E(X^2)-E(X)^2\); use \(\operatorname{Var}(aX+b)=a^2\operatorname{Var}(X)\); add variances only for independent variables; and find \(E(\bar X_n)=\mu\) and \(\operatorname{Var}(\bar X_n)=\sigma^2/n\).

18The central limit theorem and the laws of large numbers ~15 min

What is this?

Measure the same thing many times, each time with an independent random error, and add the results. Each error pushes the total a little up or down. The total drifts away from its expected value \(n\mu\), but only by about \(\sqrt n\,\sigma\), because the pushes partly cancel. The central limit theorem says more: measured in units of \(\sqrt n\,\sigma\), the scatter of the total has the shape of the bell curve, whatever the shape of a single error, as long as the repeats are independent, identically distributed and have finite variance.

This section concludes the chapter with some important theorems. All of them use the following setting.

Setting

Let \(X_1,X_2,X_3,\dots\) be a sequence of independent and identically distributed (i.i.d.) random variables. "Identically distributed" means they have a common distribution, which need not be specified. Assume \(E(X_i)=\mu\) and \(\operatorname{Var}(X_i)=\sigma^2\) are both finite, and \(\sigma^2\gt0\). Define

\[ S_n=X_1+\cdots+X_n, \] \[ \bar X_n=\frac{S_n}n,\qquad n\ge1. \]

From Exercise 2.45: \(E(S_n)=n\mu\), \(\operatorname{Var}(S_n)=n\sigma^2\) (so the standard deviation of \(S_n\) is \(\sqrt n\,\sigma\)), and \(E(\bar X_n)=\mu\), \(\operatorname{Var}(\bar X_n)=\sigma^2/n\). So \(\dfrac{S_n-n\mu}{\sqrt n\,\sigma}\) has mean 0 and variance 1 for every \(n\): it is \(S_n\) standardised.

Theorem 2.46: Central Limit Theorem

For \(a\lt b\),

\[ \begin{aligned} &\lim_{n\to\infty}P\left(a\lt\frac{S_n-n\mu}{\sqrt n\,\sigma}\le b\right)\\ &\qquad=\frac1{\sqrt{2\pi}}\int_a^be^{-x^2/2}\,dx. \end{aligned} \]

(Proof omitted.)

In words: add up many independent copies of any random variable (with finite variance) and standardise: the result has, approximately, the standard normal "bell curve" distribution, whatever the original distribution was.

Reading the formula
\(S_n-n\mu\)
how far the total is from its expected value.
\(\sqrt n\,\sigma\)
the typical size of that gap: the standard deviation of \(S_n\).
the fraction
the gap measured in standard units: mean 0 and variance 1 for every \(n\).
\(\frac1{\sqrt{2\pi}}\int_a^be^{-x^2/2}\,dx\)
the area under the standard bell curve between \(a\) and \(b\).
\(\lim_{n\to\infty}\)
the bell-curve answer is a limit; for a fixed large \(n\) it is an approximation.

The proof of the CLT uses the characteristic function of \(X\), defined as \(E(e^{i\theta X})\). This is where the complex numbers of MATH1853 Part II (Chapter P1) come into play. This topic is beyond the scope of this course and will be covered in a more advanced probability course (e.g. MATH3603); this course gives adequate preparation for it.

Since the theorem makes no specific assumption about the underlying distribution, each \(X_i\) may be a "coin-tossing", a "die-rolling", uniformly distributed ("point-picking") or exponentially distributed ("telephone-ringing"). Think of other varieties if you wish.

The central limit theorem in action

Bars: the exact distribution of the standardised sum \((S_n-n\mu)/(\sqrt n\,\sigma)\), drawn as a density (each bar's height is \(P(S_n=k)\) times \(\sqrt n\,\sigma\)). Curve: the standard normal density \(\frac1{\sqrt{2\pi}}e^{-x^2/2}\). The biased coin needs a larger \(n\) before the bars look symmetric.

Remark: the CLT as an approximation

The inequalities in the CLT can be strict or non-strict:

\[ \begin{aligned} &\lim_{n\to\infty}P\left(a\lt\frac{S_n-n\mu}{\sqrt n\,\sigma}\le b\right)\\ &=\lim_{n\to\infty}P\left(a\lt\frac{S_n-n\mu}{\sqrt n\,\sigma}\lt b\right). \end{aligned} \]

If we define

\[ \Phi(b)=\frac1{\sqrt{2\pi}}\int_{-\infty}^be^{-x^2/2}\,dx, \]

then the CLT turns into a rough approximate formula: for large \(n\),

\[ \begin{aligned} &P\big(a\sqrt n\,\sigma\lt S_n-n\mu\lt b\sqrt n\,\sigma\big)\\ &\qquad\approx\Phi(b)-\Phi(a). \end{aligned} \]

In many situations we are interested in a symmetric spread around the mean, \(a=-b\). Then, since \(\Phi(-b)=1-\Phi(b)\) (the bell curve is symmetric),

\[ \begin{aligned} P\big(|S_n-n\mu|\lt b\sqrt n\,\sigma\big)&\approx\Phi(b)-\Phi(-b)\\ &=2\Phi(b)-1. \end{aligned} \]

Extensive studies of \(\Phi\) are in the next chapter (P3). In short, the CLT says that the normalised random variable \(\dfrac{\bar X_n-\mu}{\sigma/\sqrt n}\) has (approximately) the same distribution as the standard normal distribution when \(n\) is large.

In words: to approximate a probability about a sum, subtract its mean \(n\mu\), divide by its standard deviation \(\sqrt n\,\sigma\), and read the answer from the \(\Phi\) table.

(Dividing top and bottom of \(\frac{S_n-n\mu}{\sqrt n\,\sigma}\) by \(n\) gives \(\frac{\bar X_n-\mu}{\sigma/\sqrt n}\): the same variable, written for the average.) In the exam, \(\Phi(z)\) comes from the standard normal table, the only table provided; for negative \(z\) use \(\Phi(-z)=1-\Phi(z)\).

Example: averaging measurements

A physical quantity is measured many times for accuracy. Each measurement is subject to a random error, which is reasonably assumed to be uniformly distributed between \(-1\) and \(+1\) in a conveniently chosen unit. If we take the arithmetic mean (average) of \(n\) measurements, what is the probability that it differs from the true value by less than a fraction \(\delta\) of the unit?

Answer. Let the true value be \(\mu\) and the measurements \(X_i=\mu+\xi_i\), where \(\xi_i\) is uniformly distributed on \([-1,1]\). So the \(X_i\) are i.i.d. with \(E(X_i)=\mu\) and \(\operatorname{Var}(X_i)=\operatorname{Var}(\xi_i)=\frac13\) (below). We want \(P(|\bar X_n-\mu|\lt\delta)=P(|S_n-n\mu|\lt n\delta)\). Write \(n\delta\) as \(b\sqrt n\,\sigma\) with \(\sigma=\frac1{\sqrt3}\):

\[ n\delta=\delta\sqrt{3n}\cdot\sqrt n\cdot\frac1{\sqrt3}, \]

so \(b=\delta\sqrt{3n}\), and by the CLT

\[ \begin{aligned} &P\left(|S_n-n\mu|\lt\delta\sqrt{3n}\cdot\sqrt n\cdot\tfrac1{\sqrt3}\right)\\ &\qquad\approx2\Phi(\delta\sqrt{3n})-1. \end{aligned} \]

When \(n=25\) and \(\delta=\frac15\): \(\delta\sqrt{3n}=\frac15\sqrt{75}=\sqrt3\approx1.73\), and

\[ \begin{aligned} 2\Phi(\sqrt3)-1&\approx2(0.9582)-1\\ &=0.9164\approx0.92. \end{aligned} \]

Why \(\operatorname{Var}(\xi_i)=\frac13\): the density is \(\frac12\) on \([-1,1]\), the mean is 0 by symmetry, and \(E(\xi^2)=\int_{-1}^1\frac{u^2}2\,du=\frac13\).

Example: 100 tosses of a fair coin

Here \(X_i\) is 1 for a head, 0 for a tail: \(\mu=\frac12\), \(\sigma^2=E(X_i^2)-\mu^2=\frac12-\frac14=\frac14\), \(\sigma=\frac12\). For \(n=100\): \(n\mu=50\) and \(\sqrt n\,\sigma=10\cdot\frac12=5\). So

\[ \begin{aligned} &P(|S_{100}-50|\lt10)\\ &=P(|S_{100}-50|\lt2\cdot5)\\ &\approx2\Phi(2)-1\\ &=2(0.9772)-1\\ &=0.9544. \end{aligned} \]

About 95% of the time, 100 tosses give between 41 and 59 heads. (Chapter P3 refines such approximations with the "continuity correction".)

What is this? (laws of large numbers)

Toss a coin again and again and keep the running fraction of heads. Early on it jumps about; later each new toss moves it less and less, and it settles near \(p\). The weak law says that at any single late time, being far from \(p\) is unlikely. The strong law says that, with probability 1, the running fraction actually settles down to \(p\) for good.

The laws of large numbers

Theorem 2.47: Weak Law of Large Numbers

For a fixed but arbitrary constant \(\epsilon\gt0\),

\[ \lim_{n\to\infty}P\left(\left|\frac{S_n}n-\mu\right|\ge\epsilon\right)=0. \]

In words: for a large number of trials, the average \(\bar X_n\) is very unlikely to be more than any fixed distance \(\epsilon\) from \(\mu\).

(Optional) Why it follows from the CLT. Since \(\epsilon\) is fixed, for any positive constant \(\ell\),

\[ \ell\sqrt n\,\sigma\lt\epsilon n\iff\ell\lt\frac{\epsilon\sqrt n}\sigma, \]

which holds once \(n\) is large enough. (When \(\ell\) is very large, \(n\) will also have to be large.) For such \(n\), the event \(|S_n-n\mu|\lt\ell\sqrt n\,\sigma\) is contained in \(|S_n-n\mu|\lt\epsilon n\), and by the CLT the first has probability close to \(2\Phi(\ell)-1\), which is as close to 1 as we like for \(\ell\) large. So

\[ \lim_{n\to\infty}P\left(\left|\frac{S_n}n-\mu\right|\lt\epsilon\right)=1, \]

which is the same statement (take complements).

Theorem 2.48: Strong Law of Large Numbers

With the assumptions at the beginning of this section,

\[ P\left(\lim_{n\to\infty}\frac{S_n}n=\mu\right)=1. \]

(Proof omitted.)

In words: with probability 1, the sequence of averages \(\bar X_1,\bar X_2,\dots\) actually converges to \(\mu\).

The SLLN asserts the existence of a limiting frequency equal to the theoretical probability \(\mu\), for all sample points \(\omega\) except possibly a set of probability zero (but not necessarily an empty set). The difference between the WLLN and the SLLN cannot be adequately explained without measure theory, and is left to later courses. Coin tossing gives a feel for the difference:

Coin tossing and the two laws

Let \(\Omega\) be the space of tossing a coin infinitely many times, so an element of \(\Omega\) is \(\omega=(\omega_1,\omega_2,\omega_3,\dots)\) with all \(\omega_i=H\) or \(T\). The random variables \(X_i(\omega)=1\) if \(\omega_i=H\), \(0\) if \(\omega_i=T\), are i.i.d. So \(X_i=1\) if the \(i\)-th toss was a head and 0 if a tail, and \(S_n\) is the number of heads in the first \(n\) tosses. Let \(E(X_i)=p\), the probability that the coin turns up \(H\).

Then the SLLN says that the following subset of \(\Omega\) has probability 1:

\[ \begin{aligned} A&=\left\{\omega\in\Omega\ \middle|\ \lim_{n\to\infty}\frac{S_n(\omega)}n=p\right\}\\ &=\left\{\omega\in\Omega\ \middle|\ \lim_{n\to\infty}\bar X_n(\omega)=p\right\}. \end{aligned} \]

In other words \(P(A')=0\). Here \(\Omega\) is uncountable, and we cannot explain what we mean by \(P(A)\) without discussing the probability space \((\Omega,\mathcal F,P)\). So for any continued tossing of a coin, \(\omega=(\omega_1,\omega_2,\omega_3,\dots)\) is almost surely in \(A\): we are almost sure that the long-term ratio \(\frac{\text{number of heads}}{\text{number of tosses}}\) approaches \(p\). There are of course sequences of tosses that are not in \(A\), for example \(\omega=(H,H,H,\dots)\), for which \(S_n(\omega)/n=1\); but such scenarios can happen only with probability 0.

If you know a bit about limits of sequences (e.g. MATH2241), the SLLN translates into: \(\omega\in A\) if and only if, for each \(\epsilon\gt0\), the numbers \(\bar X_N(\omega),\bar X_{N+1}(\omega),\bar X_{N+2}(\omega),\dots\) are all very close to \(p\) (the difference is \(\lt\epsilon\)) from some integer \(N\) onwards.

A picture. Imagine an infinite matrix whose rows are the sequences \(\omega=(\omega_1,\omega_2,\omega_3,\dots)\) and whose columns are \(n=1,2,3,\dots\). Pick and fix \(\epsilon\). The entry \((\omega,n)\) lights up if \(|\bar X_n(\omega)-p|\ge\epsilon\).

  • The SLLN says only a small fraction of rows (those in \(A'\), of probability 0) can have infinitely many lights. In the rows of \(A\), only finitely many lights can turn on.

Prove the "sure-thing principle": if \(P(A\mid C)\ge P(B\mid C)\) and \(P(A\mid C')\ge P(B\mid C')\), then \(P(A)\ge P(B)\).

20Summary ~4 min

  • Counting. Fundamental rule: free choices multiply. From \(n\) objects choose \(r\): ordered with replacement \(n^r\); ordered without replacement \(P^n_r=\frac{n!}{(n-r)!}\); unordered without replacement \(\binom nr=\frac{n!}{r!(n-r)!}\); unordered with replacement \(\binom{r+n-1}{n-1}\). Arrangements of \(n\) objects in groups of identical ones: \(\frac{n!}{m_1!\cdots m_\ell!}\).
  • Stirling: \(n!\approx\sqrt{2\pi n}\,(n/e)^n\); so \(\binom{2n}n\approx\frac{2^{2n}}{\sqrt{n\pi}}\).
  • Sample space \(\Omega\): all outcomes; an event is a subset. Axioms: (i) events closed under complement and countable union, \(\Omega\) an event; (ii) \(0\le P(A)\le1\); (iii) \(P(\Omega)=1\); (iv) \(P(\bigcup A_i)=\sum P(A_i)\) for pairwise disjoint \(A_i\).
  • Equally likely outcomes: \(P(A)=|A|/|\Omega|\). Rules: \(P(\emptyset)=0\), \(P(A')=1-P(A)\), \(A\subset B\Rightarrow P(A)\le P(B)\), \(P(A\cup B)=P(A)+P(B)-P(A\cap B)\).
  • Conditional probability: \(P(A\mid B)=\frac{P(A\cap B)}{P(B)}\) (\(P(B)\gt0\)); \(P(\cdot\mid B)\) is itself a probability.
  • Total probability: \(P(A)=\sum_iP(A\mid B_i)P(B_i)\) for a partition \(B_1,\dots,B_n\). Bayes: \(P(B_i\mid A)=\frac{P(A\mid B_i)P(B_i)}{\sum_jP(A\mid B_j)P(B_j)}\).
  • Independence: \(P(A\cap B)=P(A)P(B)\). Disjoint events with positive probabilities are never independent. Complements of independent events are independent.
  • A random variable is a function \(X:\Omega\to\mathbb R\). Discrete: pmf \(P(X=x)\), \(\sum=1\). With a density \(f\): \(f\ge0\), \(\int f=1\), \(P(a\le X\le b)=\int_a^bf\), and \(P(X=x)=0\).
  • Distribution function \(F(x)=P(X\le x)\): a step function for discrete \(X\); \(F(x)=\int_{-\infty}^xf\) and \(F'=f\) with a density.
  • Expectation: \(E(X)=\sum xP(X=x)\) or \(\int uf(u)\,du\); \(E(g(X))=\sum g(x)P(X=x)\) or \(\int g(u)f(u)\,du\). \(E(aX+bY)=aE(X)+bE(Y)\) always; \(E(XY)=E(X)E(Y)\) if independent.
  • Joint pmf \(p(x,y)\): marginals by adding rows or columns; \(X,Y\) independent iff \(p(x,y)=p_X(x)p_Y(y)\) for every cell.
  • Variance: \(\operatorname{Var}(X)=E[(X-\mu)^2]=E(X^2)-E(X)^2\); \(\operatorname{Var}(aX+b)=a^2\operatorname{Var}(X)\); \(\operatorname{Var}(X+Y)=\operatorname{Var}(X)+\operatorname{Var}(Y)\) if independent. For the mean of \(n\) i.i.d. variables: \(E(\bar X_n)=\mu\), \(\operatorname{Var}(\bar X_n)=\sigma^2/n\).
  • Density of \(Y=g(X)\): find \(P(Y\le y)\) in terms of \(X\), then differentiate. \(f_{aX+b}(y)=\frac1{|a|}f\big(\frac{y-b}a\big)\); \(f_{X^2}(w)=\frac{f(\sqrt w)+f(-\sqrt w)}{2\sqrt w}\).
  • CLT: \(P\big(a\lt\frac{S_n-n\mu}{\sqrt n\sigma}\le b\big)\to\Phi(b)-\Phi(a)\). Laws of large numbers: \(S_n/n\to\mu\) (in probability: weak; with probability 1: strong).
Method: a conditional / Bayes question
  1. Do: Name the events: the "causes" \(B_1,\dots,B_n\) (which urn, machine, factory) and the "evidence" \(A\). The causes are the first branches of the tree and the evidence is the result seen at the end of a path; they must not overlap and must cover every case.
  2. Do: Write down what is given: priors \(P(B_i)\) and likelihoods \(P(A\mid B_i)\). (Draw a tree if it helps.) These are the labels on the two levels of branches, and they are all the tree needs.
  3. Do: Total probability: \(P(A)=\sum P(A\mid B_i)P(B_i)\). Each path ending in the evidence is one way it can happen; the paths do not overlap, so their probabilities add.
  4. Do: Bayes: \(P(B_i\mid A)=P(A\mid B_i)P(B_i)/P(A)\). For "the next one is also ...", compute \(P(A_1\cap A_2)\) by total probability and divide by \(P(A_1)\). Reasoning backwards: cause \(i\)'s share of all the probability that reaches the evidence. Repeated draws share the same hidden cause, so both must sit on one path.
Method: a density question
  1. Do: Normalising constant: solve \(\int_{-\infty}^{\infty}f=1\) (only over where \(f\ne0\)); split at \(0\) for \(|x|\), and at sign changes for things like \(|x^2-1|\). All the sand must add up to one bucket; where \(f=0\) there is none, and the formula changes where the absolute value switches sign.
  2. Do: Distribution function: \(F(x)=\int_{-\infty}^xf\), piece by piece: 0 to the left of the range, 1 to the right. \(F\) is the running total of sand: nothing yet before the range starts, everything once it ends.
  3. Do: Moments: \(E(X^n)=\int u^nf(u)\,du\) (by parts for \(u^ne^{-u}\)); then \(\operatorname{Var}(X)=E(X^2)-E(X)^2\) and \(\operatorname{Var}(aX+b)=a^2\operatorname{Var}(X)\). A moment is the balance-point average of \(u^n\); the spread needs only the first two moments.

Mutually exclusive means \(A\cap B=\emptyset\), so \(P(A\cap B)=0\), not \(P(A)P(B)\) (that is independence). So \(P(A\cup B)=0.3+0.4=0.7\).

2. "\(X\) has density \(f\). Find the density of \(Y=1-2X\)."

\[ \begin{aligned} P(Y\le y)&=P(1-2X\le y)\\ &=P\!\left(X\le\frac{1-y}2\right), \end{aligned} \] \[ f_Y(y)=f\!\left(\frac{1-y}2\right)\cdot\left(-\frac12\right). \]
Hint

Can a density be negative? What happens to the inequality \(1-2X\le y\) when you divide by \(-2\)?

Answer
\[ \begin{aligned} 1-2X\le y&\iff-2X\le y-1\\ &\iff X\ge\tfrac{1-y}2: \end{aligned} \]

dividing by a negative number reverses the inequality. So \(P(Y\le y)=1-F\big(\frac{1-y}2\big)\), and \(f_Y(y)=\frac12f\big(\frac{1-y}2\big)\ge0\), in agreement with \(\frac1{|a|}f\big(\frac{y-b}a\big)\) for \(a=-2\), \(b=1\) (section 15).

3. "\(X\) and \(Y\) are independent with \(\operatorname{Var}(X)=4\), \(\operatorname{Var}(Y)=1\). Find \(\operatorname{Var}(3X-2Y+5)\)."

\[ \begin{aligned} \operatorname{Var}(3X-2Y+5)&=3(4)-2(1)+5\\ &=15. \end{aligned} \]
Hint

Propositions 2.43 and 2.44: what happens to constants that multiply, and to constants that are added?

Answer

Coefficients are squared and added constants disappear:

\[ \begin{aligned} &\operatorname{Var}(3X-2Y+5)\\ &=9\operatorname{Var}(X)+4\operatorname{Var}(Y)\\ &=36+4=40 \end{aligned} \]

(independence lets the variances add; \((-2)^2=4\)).

23Concept checks ~1 min

1. Can \(f(x)=2\) for \(0\le x\le\frac12\) (and 0 otherwise) be a density, even though \(f\) is bigger than 1?

Answer

Yes: \(f\ge0\) and \(\int_0^{1/2}2\,dx=1\). A density value is not a probability; only areas under \(f\) are. (Probabilities \(P(X=x)\) of a discrete variable can never exceed 1.)

2. \(A\subset B\), \(P(A)=0.3\), \(P(B)=0.5\). Find \(P(A\mid B)\) and \(P(B\mid A)\).

Answer

\(A\cap B=A\). \(P(A\mid B)=0.3/0.5=0.6\); \(P(B\mid A)=0.3/0.3=1\) (if \(A\) happens, \(B\) surely does).

3. Two events each have probability \(\frac12\) and are independent. Can they be mutually exclusive?

Answer

No: independence gives \(P(A\cap B)=\frac14\ne0\).

4. \(E(X)=2\) and \(\operatorname{Var}(X)=3\). Find \(E(X^2)\), \(E((X+1)^2)\) and \(\operatorname{Var}(5-2X)\).

Answer
\[ \begin{aligned} E(X^2)&=\operatorname{Var}(X)+E(X)^2\\ &=3+4=7. \end{aligned} \] \[ \begin{aligned} E((X+1)^2)&=E(X^2)+2E(X)+1\\ &=7+4+1=12. \end{aligned} \]

\(\operatorname{Var}(5-2X)=(-2)^2\cdot3=12\).

5. \(X\) has a density. Is \(P(X\lt3)=P(X\le3)\)? If \(X\) is the score of a die, is it?

Answer

With a density, yes: \(P(X=3)=0\). For a die, no:

\[ \begin{aligned} &P(X\le3)-P(X\lt3)\\ &\quad=P(X=3)=\tfrac16. \end{aligned} \]

6. The average \(\bar X_n\) of \(n\) independent measurements, each with standard deviation \(\sigma\), has standard deviation \(\sigma/\sqrt n\). How many measurements make the standard deviation of the average one tenth of \(\sigma\)?

Answer

\(\sigma/\sqrt n=\sigma/10\) gives \(n=100\). Accuracy improves only like \(\sqrt n\) (Exercise 2.45).
