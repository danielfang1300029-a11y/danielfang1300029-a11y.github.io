MATH1851 Revision Bundle (HKU, Calculus and ODEs)
=================================================

How to open
1. Unzip the whole folder (keep all files together, including the "mathjax" folder).
2. Double-click index.html. It opens in your web browser (Chrome, Safari, Edge, Firefox).
3. Start from that page: Part 1 = chapter notes (learn each lecture), Part 2 = exam guide
   (every past-paper question, sorted by type, with hints and full solutions).

Notes
- Works offline. With internet the pages use nicer fonts; without it they use your system fonts.
- On a phone: unzip with a files app and open index.html in the browser. Some phone apps
  preview HTML without following links; if links do nothing, open it in Chrome/Safari instead.
- Do not rename or move individual files: the pages link to each other by file name.

Contents: index.html, note-L1 ... note-L17, note-O1 ... note-O4, note-LT (chapter notes),
guide-L1 ... guide-LT (exam guide pages; L11 has no exam questions, so no guide page).
