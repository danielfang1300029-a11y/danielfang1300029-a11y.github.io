Ch.11 Monopoly · Exam guide

← Start HereChapter note · Ch.11Next: guide Ch.12

Every Ch.11 question from 2020 Spring to 2025 Spring Supplementary (110 unique questions, no repeats) sorted into seven strategies. This chapter is predictable: almost every final opens a monopoly block with one demand line and one MC, then asks a chain of follow-ups. Learn the chain and drill the arithmetic.

0How Ch.11 is examined

  • Where: finals only (and the 2025 Spring Supplementary), usually as a block of 4–8 linked questions on one monopoly near the end of the paper; 14 sittings 2020–2025 have Ch.11 questions.
  • The chain: \(Q_m, P_m\) → markup / elasticity / profit → efficient Q and DWL → a policy (price ceiling, subsidy, licence fee) → DWL change and long-run stay-or-exit. A slip in the first blank carries through the block, so check \(Q_m\) twice.
  • Format (unchanged since 2020): fill-in numeric blanks to 2 decimal places, A/B direction blanks ("increases / decreases", "higher / lower", "stay in / exit"), MCQ, True/False, "how many are true". No marks are shown on the papers.
  • No formula sheet. Memorise the box below.
Memorise for Ch.11
  • Inverting \(Q = x - yP\): \(P = x/y - Q/y\). MR has the same intercept and twice the slope.
  • Profit max: MR = MC; price from DEMAND. Efficient: demand = MC.
  • Markup % \(= (P - MC)/MC \times 100\). Point elasticity \(= (\Delta Q/\Delta P)(P/Q)\). Pricing rule \(P\) \(= \dfrac{\varepsilon}{1+\varepsilon} MC\).
  • DWL triangle \(\tfrac12 (P_m - MC(Q_m))(Q_e - Q_m)\); for constant MC \(Q_e = 2Q_m\).
  • Fixed costs and lump sums never change Q or P; long run: stay iff profit ≥ 0.
  • Ceiling: sell \(Q_d(P_c)\); stay iff \((P_c - MC)Q_c \ge FC\); lowest ceiling from \(bQ^2 - (a - MC)Q + FC = 0\), larger root.
  • Subsidy s (firm or consumer): \(MR = MC - s\); removes the DWL when \(s = bQ_e\).
  • Integer units: MR of unit n \(= a - b(2n - 1)\).

Looks likeThe same monopoly, then "a price ceiling at $Pc": output, DWL change, fixed-cost threshold, lowest ceiling with a given FC.

C11.1Monopoly optimum: MR = MC, price off demand

29 parts, 29 unique · newest first within each form · Note §3 Profit maximisation

Do
  1. Demand printed as \(Q = x - yP\)? Invert: \(P\) \(= \dfrac{x}{y} - \dfrac{1}{y}Q\), so \(a = x/y\), \(b = 1/y\).
  2. \(MR = a - 2bQ\). Set \(MR = MC\): constant MC gives \(Q_m = \dfrac{a - MC}{2b}\); rising \(MC = c_0 + c_1Q\) gives \(Q_m\) \(= \dfrac{a - c_0}{2b + c_1}\).
  3. \(P_m = a - bQ_m\) (demand). Check the blank order.
  4. Follow-ups from the same point:
    • Markup % \(= (P_m - MC)/MC \times 100\).
    • Elasticity \(= -\dfrac{1}{b} \cdot \dfrac{P_m}{Q_m}\) (= \(-y P_m/Q_m\) for \(Q = x - yP\)).
    • Profit \(= P_mQ_m - TC(Q_m)\), fixed cost included.
    • Reverse (ATC minimum at the optimum): \(MC = ATC\), so \(B = (P - ATC)/Q\), \(A = P + BQ\).
Ready answer · linear demand, constant MC c

\(Q_m = \dfrac{a - c}{2b}\), \(P_m = \dfrac{a + c}{2}\), \(Q_e\) \(= \dfrac{a - c}{b}\) \(= 2Q_m\), DWL \(= \dfrac{(a - c)^2}{8b}\), profit before FC \(= \dfrac{(a - c)^2}{4b}\) = 2 × DWL.

Check: P = 160 − 0.2Q, c = 6 gives \(P_m = 83\), \(Q_m = 385\), DWL 14822.5, profit 29645.

A monopolist faces a demand curve of P = 70 − 0.4Q and has a constant marginal cost of $2 per unit.

  1. Unregulated \(Q_m, P_m\) first. A ceiling \(P_c\) with \(MC \le P_c \lt P_m\) binds.
