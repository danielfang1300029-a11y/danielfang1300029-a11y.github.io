Cx.1System classification: causal, linear, time-invariant, static

3 parts · 22 marks · ELEC2245 2023–2024 (Q1(a) on every paper) · not taught in MECH2413

What you need (beyond MECH2413)

A system is a rule that turns an input signal \(u(t)\) into an output signal \(y(t)\). These questions ask four yes/no questions about the rule. The MECH2413 slides only name “linear” and “time-invariant” (note-C2 §2); causal and static are new here.

  • Causal: the output now uses the input only from now and the past. It cannot see the future. Test: list every time at which \(u\) is read. If any of them can be later than \(t\) (\(u(t+1)\), an integral up to \(t+2\), \(u(t^3)\) when \(t\gt1\)), the system is noncausal.
  • Static (also called memoryless): the output now uses the input only at this same instant \(t\). Test: \(y(t)\) is a plain formula in \(u(t)\) and \(t\). A derivative \(\dot y\), an integral, or any other time argument (\(u(t-1)\), \(u(t^3)\)) makes it dynamic: it has to remember (or predict) other values.
  • Linear: doubling the input doubles the output, and the response to a sum of inputs is the sum of the responses (this is called superposition). Test: \(u\) (and its integrals or derivatives) appears only to the first power, multiplied only by numbers or functions of \(t\), with nothing added on. \(u^2\), \(\sqrt{u^3}\), \(\sin u\), \(\ln u\), \(u+1\) all make it nonlinear.
  • Time-invariant: delaying the input by \(T\) only delays the output by \(T\); the rule does not read the clock. Test: \(t\) appears nowhere except as \(u(t\pm\text{const})\) or as integral limits \(t\pm\text{const}\). An explicit \(t\) outside \(u\) (\(\cos\pi t\), \(\sin t\), a weight \(\tau\) inside an integral) or a stretched argument (\(u(2t)\), \(u(t^3)\)) makes it time-varying.

Formal tests, for a one-line proof:

\[\begin{aligned}&\text{Linear: }u=a u_1+b u_2\\&\quad\Rightarrow y=a y_1+b y_2\text{ for all }a,b.\\&\text{Time-inv.: input }u(t-T)\\&\quad\Rightarrow\text{output }y(t-T).\end{aligned}\]

In words: a linear system adds and scales like ordinary arithmetic; a time-invariant one behaves the same on Monday as on Tuesday.

Why it matters: Laplace transforms and transfer functions (all of MECH2413 C2) work only for systems that are linear and time-invariant; a controller built in real time must be causal.

Predictable · how to spot it
Looks like
“Please find whether the following systems are causal/noncausal, linear/nonlinear, time-invariant/time-varying, or static/dynamic”, then three to five one-line rules: \(y=\dots\), \(\dot y=\dots\), or an integral.
Do
For each rule, run the four tests in a fixed order (causal, linear, time-invariant, static). Write each verdict with a reason of a few words. If time-invariance is unclear, do the formal shift test in one line. About ½ mark per verdict (Dec 2024: 10 marks for 20 verdicts).
Watch
Constants that look like functions are just numbers: \(\sin(\pi/3)=0.866\), \(2\ln3=2.197\); they do not make a system time-varying. Any \(\dot y=\dots\) rule is dynamic. One time \(t\) at which the future is read is enough for “noncausal”. \(\sin(t)\,u(t)\) is linear: \(\sin t\) is a coefficient, not a function of \(u\).

Q1. Please answer the following four sub-questions. (a) Please find whether the following systems are causal/noncausal, linear/nonlinear, time-invariant/time-varying, or static/dynamic.

\[\begin{aligned}&(a1)\ \ y(t)=\sin(u(t))\\&(a2)\ \ \dot y(t)=\cos(\pi t)\,u(t)\\&(a3)\ \ y(t)=u(t^3)\\&(a4)\ \ y(t)=2\ln 3u(t)\\&(a5)\ \ y(t)=\int_{-\infty}^{t+1}6u^2(\tau)\,d\tau\end{aligned}\]

Parts (b)–(d) of this question are under C2.6 Routh–Hurwitz and C2.3 Time response.

Hint

Four tests per rule, in the order of the box above. For (a3), try \(t=2\): which input time does \(y(2)\) read?

Solution
  1. (a1) \(y=\sin(u(t))\): causal (reads only \(u(t)\)); nonlinear (\(\sin 2u\ne2\sin u\)); time-invariant (no \(t\) outside \(u\)); static (only the present value of \(u\)).
  2. (a2) Integrate: \(y(t)=y(t_0)+\int_{t_0}^{t}\cos(\pi\tau)u(\tau)\,d\tau\). Causal (past and present only); linear (\(u\) to the first power); time-varying (the coefficient \(\cos\pi t\) reads the clock: a delayed input meets a different coefficient); dynamic (\(\dot y\): the output accumulates).
  3. (a3) \(y=u(t^3)\): noncausal (\(y(2)=u(8)\): the input 6 s in the future); linear; time-varying (input \(u(t-T)\) gives \(u(t^3-T)\), but the delayed output is \(u((t-T)^3)\): not equal); dynamic (reads \(u\) at time \(t^3\ne t\)).

    Which input time \(\tau\) the output at time \(t\) reads. Above the dashed line \(\tau=t\) means the future: for \(-1\lt t\lt0\) and \(t\gt1\), \(y=u(t^3)\) reads ahead, so it is noncausal.

  4. (a4) Read as \(y=(2\ln3)\,u(t)=2.197\,u(t)\), a constant gain: causal · linear · time-invariant · static.
  5. (a5) Noncausal (integrates up to \(t+1\), one second ahead); nonlinear (\(u^2\)); time-invariant (input \(u(t-T)\): put \(\sigma=\tau-T\), the integral becomes \(\int_{-\infty}^{t+1-T}6u^2(\sigma)\,d\sigma=y(t-T)\)); dynamic (an integral over past and future values).

Give a reason with each verdict (“time-varying because \(\cos\pi t\) multiplies \(u\)”); a bare list of words does not show that the test was done.

(a1) causal, nonlinear, time-invariant, static
(a2) causal, linear, time-varying, dynamic
(a3) noncausal, linear, time-varying, dynamic
(a4) causal, linear, time-invariant, static
(a5) noncausal, nonlinear, time-invariant, dynamic

(a4) is printed “\(2\ln 3u(t)\)” with no brackets. Reading used: \((2\ln 3)\,u(t)\). If it means \(2\ln(3u(t))\), the only change is nonlinear (still causal, time-invariant, static).

Q1. Please answer the following two sub-questions. (a) Please find whether the following systems are causal/noncausal, linear/nonlinear, time-invariant/time-varying, or static/dynamic.

\[\begin{aligned}&(a1)\ \ y(t)=\sin(t)\,u(t)\\&(a2)\ \ \dot y(t)=\sin(\pi/3)\,u(t)\\&(a3)\ \ y(t)=\int_{-\infty}^{\tau}5\tau u^2(\tau)\,d\tau\end{aligned}\]

(a2): is \(\sin(\pi/3)\) a function of time? (a3): the weight \(5\tau\) is the clue for time-invariance.

(a2) causal, linear, time-invariant, dynamic
(a3) causal, nonlinear, time-varying, dynamic

Cx.2Electric-circuit and state-space models

7 parts · 35 marks · ELEC2245 2022–2023 (Q2 both years) · not taught in MECH2413

What you need (beyond MECH2413)

Three circuit elements (voltage \(v\) in volts V, current \(i\) in amperes A):

\[\begin{aligned}&\text{resistor: }v=Ri\quad(R\text{ in }\Omega)\\&\text{inductor: }v=L\,\frac{di}{dt}\quad(L\text{ in H})\\&\text{capacitor: }i=C\,\frac{dv}{dt}\quad(C\text{ in F})\end{aligned}\]

Two laws. Kirchhoff's voltage law (KVL): the voltages around any closed loop add to zero (the source voltage equals the sum of the drops). Kirchhoff's current law (KCL): the currents into a junction add to zero (what flows in flows out).

Impedance. With zero initial conditions, Laplace turns each element into \(V(s)=Z(s)I(s)\): \(Z_R=R\), \(Z_L=sL\), \(Z_C=\dfrac1{sC}\). Impedances in series add; in parallel, \(Z=\dfrac{Z_1Z_2}{Z_1+Z_2}\). A voltage divider gives

\[\frac{V_{\text{out}}(s)}{U(s)}=\frac{Z_{\text{out}}}{Z_{\text{total}}}.\]

In words: the source voltage is shared among the elements in proportion to their impedances.

Analogy with the spring–mass–damper (note-C2 §1): series RLC with charge \(q\): \(L\ddot q+R\dot q+q/C=u\) has the same form as \(m\ddot x+b\dot x+kx=F\). So \(L\leftrightarrow m\), \(R\leftrightarrow b\), \(1/C\leftrightarrow k\), voltage \(\leftrightarrow\) force.

State-space model. The state (note-C2 §2) is the set of numbers that, with the future input, fixes the future. For circuits, take one state per energy store: each inductor current and each capacitor voltage. Write

\[\dot{\mathbf x}=A\mathbf x+Bu,\qquad y=C\mathbf x+Du.\]

In words: the rate of change of each state is a weighted sum of the states and the input; the output is read off the states.

Recipe: for each inductor, \(L\,\dfrac{di}{dt}=\) (voltage across it, from KVL); for each capacitor, \(C\,\dfrac{dv}{dt}=\) (current into it, from KCL). Rewrite every right-hand side using states and \(u\) only. Check: the transfer function \(C(sI-A)^{-1}B+D\) must equal the one from impedances (its denominator is \(\det(sI-A)\)).

Sinusoidal steady state (note-C2 §22): for a stable \(G\), input \(u=U_0\sin\omega t\) gives, once the transient has died,

\[y_{ss}=U_0|G(j\omega)|\sin\big(\omega t+\angle G(j\omega)\big).\]

In words: the output is a sine at the same frequency, scaled by the gain \(|G(j\omega)|\) and shifted by the phase \(\angle G(j\omega)\).

Why states are inductor currents and capacitor voltages: these cannot jump (they store energy), and their derivatives appear in the element laws.

Predictable · how to spot it
Looks like
An RLC circuit with a voltage source \(u\). (a) Transfer function from \(u\) to the capacitor voltage, zero initial conditions. (b) State-space model with the states named for you. (c) Numbers and \(u=1(t)\) V: find \(y(t)\). (d) \(u=\sin t\) V: steady-state \(y(t)\).
Do
(a) Replace each element by its impedance; voltage divider; multiply out to a polynomial ratio. (b) One equation per energy store (KVL for \(L\), KCL for \(C\)); collect \(A,B,C,D\); check \(\det(sI-A)\) against (a). (c) \(Y=G(s)/s\), partial fractions, table, units V and s. (d) Evaluate \(G(j\omega)\); magnitude and angle; write \(y_{ss}\).
Watch
DC check before you finish: capacitor = open circuit, inductor = short circuit (E22M: \(L_2\) shorts \(C\), so \(v_c\to0\)). A value \(L_1=0\) removes that inductor and its state; use the transfer function as the question says. The angle of \(1/(1+3j)\) is \(-\tan^{-1}3\), not \(+\).
Ready answer · series RLC, output across \(C\) \[\begin{aligned}\frac{V_C(s)}{U(s)}&=\frac{1}{LCs^2+RCs+1}\\&=\frac{1/(LC)}{s^2+\frac RL s+\frac1{LC}}\end{aligned}\]

States \(x_1=i\), \(x_2=v_C\):

\[A=\begin{bmatrix}-R/L&-1/L\\1/C&0\end{bmatrix},\ B=\begin{bmatrix}1/L\\0\end{bmatrix},\] \[C=\begin{bmatrix}0&1\end{bmatrix},\ D=0.\]

In words: a second-order system with \(\omega_n=1/\sqrt{LC}\) and \(2\zeta\omega_n=R/L\): the resistor provides the damping.

Learn it: note-C2 §6 (transfer function), §7 (inverse transform), §22 (frequency response).

Q2. Consider the RLC circuit shown in Fig. 2.

Fig. 2 (redrawn): series loop of source \(u\), resistor \(R\), inductor \(L\) and capacitor \(C\); current \(i\).

(a) Define the voltage \(u\) of the voltage source as the input and the voltage on the capacitor \(C\) as the output. Assuming zero initial conditions, find the transfer function of the system with the selected input-output pair.

(b) Let \(x_1=i\), and \(x_2=v\), where \(i\) and \(v\) are current through the inductor \(L\) and the voltage on the capacitor \(C\), respectively. Choose the same input-output pair as that in part (a). Find the state-space model of the circuit.

(c) Let \(R=3\ \Omega\), \(L=1\) H, and \(C=1/2\) F. Suppose \(u(t)=1(t)\) V, and the circuit has zero initial conditions. Based on the transfer function obtained in part (a), find the time domain solution of the system output \(y(t)\).

(d) Suppose the input change to \(u(t)=\sin(t)\) V. Please calculate the steady-state system output \(y(t)\) with the same parameters as given in (c).

Hint

(a) Series loop: voltage divider with \(Z_C\) over \(R+sL+Z_C\). (b) One equation for \(L\) (KVL), one for \(C\). (c) The poles come out at \(-1\) and \(-2\). (d) \(G(j1)\); the formula sheet gives \(\tan^{-1}3\).

Solution
  1. (a) KVL round the loop and the capacitor law: \(u=Ri+L\dot i+v\), \(i=C\dot v\). With zero initial conditions, \(U=(R+sL+\frac1{sC})I\) and \(V=\frac{1}{sC}I\), so \[\begin{aligned}\frac{V(s)}{U(s)}&=\frac{1/(sC)}{R+sL+1/(sC)}\\&=\frac{1}{LCs^2+RCs+1}.\end{aligned}\]
  2. (b) Inductor: \(L\dot x_1=u-Rx_1-x_2\) (KVL). Capacitor: \(C\dot x_2=x_1\) (the loop current flows into \(C\)). Output \(y=x_2\): \[\begin{aligned}\dot{\mathbf x}&=A\mathbf x+Bu,\quad y=C\mathbf x,\\A&=\begin{bmatrix}-\frac RL&-\frac1L\\\frac1C&0\end{bmatrix},\ B=\begin{bmatrix}\frac1L\\0\end{bmatrix},\end{aligned}\] \(C=\begin{bmatrix}0&1\end{bmatrix}\), \(D=0\). Check: \(\det(sI-A)=s^2+\frac RL s+\frac1{LC}\), the denominator of (a) divided by \(LC\).
  3. (c) \(LC=0.5\ \text{s}^2\), \(RC=1.5\) s: \(G(s)=\dfrac{1}{0.5s^2+1.5s+1}=\dfrac{2}{(s+1)(s+2)}\). Unit step: \[\begin{aligned}Y(s)&=\frac{2}{s(s+1)(s+2)}\\&=\frac1s-\frac{2}{s+1}+\frac{1}{s+2}\end{aligned}\] (cover-up: at \(s=0\): \(2/2=1\); at \(s=-1\): \(2/(-1\cdot1)=-2\); at \(s=-2\): \(2/((-2)(-1))=1\)). So \(y(t)=1-2e^{-t}+e^{-2t}\) V for \(t\ge0\). Checks: \(y(0)=0\); \(y\to1\) V, since at DC the capacitor is an open circuit and takes the whole source voltage.

    Step response (overdamped: two real poles), no overshoot, final value 1 V.

  4. (d) The poles \(-1,-2\) are in the left half-plane, so the transient dies and the steady state is the frequency response at \(\omega=1\) rad/s: \[\begin{aligned}G(j1)&=\frac{2}{(j)^2+3j+2}=\frac{2}{1+3j},\\|G|&=\frac{2}{\sqrt{10}}=0.632,\\\angle G&=-\tan^{-1}3=-71.57^\circ.\end{aligned}\]

    Input \(\sin t\) V (grey) and the steady-state output (blue): amplitude 0.632 V, lagging by 71.57° (1.249 rad, i.e. 1.249 s at 1 rad/s).

In (d) say why the steady state exists (poles in the left half-plane) before using \(G(j\omega)\).

(b) \(\dot x_1=\frac{u-Rx_1-x_2}{L}\), \(\dot x_2=\frac{x_1}{C}\), \(y=x_2\)
(c) \(y(t)=1-2e^{-t}+e^{-2t}\) V, \(t\ge0\)

Cx.3Analogue-computer simulation diagrams

2 parts · 11 marks · MECH2004 2005, 2006 (last part of a modelling question) · not taught in MECH2413

What you need (beyond MECH2413)

An analogue computer solves a differential equation with electronics: each signal is a voltage, and a few standard op-amp blocks are wired so that the voltages obey the equation. A simulation diagram is the wiring plan drawn with standard symbols.

The four symbols. Numbers at an amplifier input are its input weights (1 or 10 on a real machine).

  • Coefficient potentiometer (circle): output \(=k\times\) input, \(0\le k\le1\). A gain above 1 is a pot plus an amplifier input of weight 10 (gain 5 = pot 0.5 into a “10” input).
  • Summer (triangle): output \(=-(w_1x_1+w_2x_2+\dots)\). Note the minus sign.
  • Integrator (triangle with a bar): output \(=-\int(w_1x_1+w_2x_2+\dots)\,dt\), starting from its initial condition.
  • Inverter: a summer with one input of weight 1: output \(=-\)input.

Why the minus signs: the op-amp in each block is wired as an inverting amplifier. Every summer and integrator flips the sign, and the diagram must keep track of it.

Recipe. (1) Write the closed-loop differential equation and solve it for the highest derivative. (2) Chain one integrator per order: highest derivative in, lower derivatives out. (3) Feed each term back to the first integrator through a pot. (4) Follow signs along every path; insert an inverter where a sign is wrong. (5) Check by reading the finished diagram back into an equation.

Decision procedure
  1. Get the equation. If the closed loop is given as a transfer function, cross-multiply: \(\frac{Y}{R}=\frac{b_0}{s^2+a_1s+a_0}\) gives \(\ddot y=b_0r-a_1\dot y-a_0y\). Cue: “simulate the closed-loop system” after a part that found \(y(s)/r(s)\).
  2. Keep the loop visible if you can (looks like the block diagram the marker has in mind): summer forming the error \(e=r-y\), controller, plant. Each plant block \(\frac{b}{s+a}\) is one integrator with a self-feedback pot \(a\) and an input pot \(b\) (ready answer).
  3. PI controller \(K_p(1+\frac1{T_is})\): a summer adding \(K_pe\) and the integrator output \(\frac{K_p}{T_i}\int e\,dt\).
  4. Count sign flips on each path from one signal to the next. Two parallel paths that meet at a summer (P and I parts) must arrive with the same sign; if they differ by one flip, add an inverter on one of them. Trap: forgetting that the integrator also inverts.
  5. Feedback must be negative overall: around the main loop, the number of inverting blocks must be odd. Trap: positive feedback makes the simulated output grow without bound.
  6. Read back: write each block's output equation and eliminate; it must reproduce the closed-loop transfer function.
Ready answer · first-order block \(\dfrac{b}{s+a}\)

Cx.4Lead and lag compensation

4 parts · 20 marks · ELEC2245 May 2024 Q6(c) · MECH2004 2006, 2010 (root-locus comments) · not taught in MECH2413

What you need (beyond MECH2413)

A compensator is a controller with one zero and one pole, \(C(s)=\dfrac{s+z}{s+p}\), placed in front of the plant.

  • Lead (zero nearer the origin, \(z\lt p\)): like a PD controller with its derivative action filtered. On a root locus it pulls the branches and the asymptote centre to the left: faster, better damped, stable for larger gains. On a Bode plot it adds positive phase (lead) near the crossover, raising the phase margin.
  • Lag (pole nearer the origin, \(p\lt z\)): like a PI controller with a limited integral. It pushes the locus to the right (slower, less stable) unless the pair is a dipole (pole and zero very close, near the origin). A dipole leaves the locus almost unchanged but raises the low-frequency gain by \(z/p\), cutting steady-state error.

Root-locus facts used here (sketching rules: note-C2 §13 and its Beyond box): with \(n\) poles and \(m\) zeros, \(n-m\) branches go to infinity along asymptotes centred at

\[\sigma_a=\frac{\sum\text{poles}-\sum\text{zeros}}{n-m}.\]

In words: adding a pair moves the centre by \((z-p)/(n-m)\) (in terms of the root locations \(-p\), \(-z\)): left if the zero is nearer the origin (lead), right if the pole is.

Bode lead design with \(D_c=\dfrac{T_Ds+1}{\alpha T_Ds+1}\), \(0\lt\alpha\lt1\) (the ELEC2245 form, formula sheet gives the last two lines):

\[\begin{aligned}\sin\phi_{\max}&=\frac{1-\alpha}{1+\alpha},\\\omega_{\max}&=\frac{1}{T_D\sqrt\alpha},\\T_D&=\frac{1}{\sqrt\alpha\,\omega_c}.\end{aligned}\]

In words: the smaller \(\alpha\), the more phase the network can add (at most \(\phi_{\max}\), reached at \(\omega_{\max}\), midway between the zero and pole on a log scale); there its gain is \(1/\sqrt\alpha\).

Why “extra margin”: the lead's gain \(1/\sqrt\alpha\) pushes the crossover to a higher frequency, where the plant has less phase. The extra degrees are a guess at that loss; if the plant's phase falls faster, the guess is too small and you must iterate.

Decision procedure
  1. “Comment on adding a pole and zero” with root-locus sketches → decide lead or lag by which is nearer the origin. Lead: centre and branches move left, more damping, faster settling, larger stable gain range. Lag: move right, less stable, slower; a close pair near the origin (dipole) keeps the transient and improves steady-state accuracy. Quote the centroid shift.
  2. “Choose controller (a) or (b)” → compute the new asymptote centre for each, and if time allows the new stability limit (Routh). Pick the one that moves the locus left (unless the aim is steady-state error).
  3. “Design a lead compensator for \(K_p\) and PM” → (i) set the gain \(K\) from the error constant; (ii) read PM of \(KG\); (iii) lead needed \(=\) PM wanted \(-\) PM now \(+\) extra; (iv) \(\alpha\) from \(\sin\phi_{\max}\); (v) new crossover where \(|KG|=\sqrt\alpha\); (vi) \(T_D=1/(\sqrt\alpha\,\omega_c)\); (vii) check the PM achieved; if short, raise \(\phi_{\max}\) and repeat.
  4. Trap: stopping after step (vi). The recipe is approximate; the marker wants the check.
  5. Trap: forgetting that \(D_c(0)=1\), so the lead does not change \(K_p\); the gain \(K\) set in step (i) stays.

Cx.5Ziegler–Nichols tuning

2 parts · 8 marks · MECH2004 Dec 2011 (Q3(b) and Q4(vii)) · not taught in MECH2413

What you need (beyond MECH2413)

Ziegler–Nichols (Z–N) tuning is a recipe for setting PID gains from one simple experiment, without a model of the plant. The controller is written \(u=K_p\big(e+\frac1{T_i}\int e\,dt+T_d\dot e\big)\): \(T_i\) is the integral time, \(T_d\) the derivative time (note-C1 §11 has the same law with \(K_I=K_p/T_i\), \(K_D=K_pT_d\)).

Open-loop (reaction-curve) method. Step the plant input with the loop open; the output traces an S-shaped curve. Draw the tangent at the steepest point (the inflection point): where it crosses the starting level gives the dead time \(L\); its slope per unit step is \(R\); where it meets the final level gives \(L+T\).

Example plant \(1/(s+1)^3\), unit step: inflection at 2 s, slope \(R=0.271\ \text{s}^{-1}\), \(L=0.81\) s, \(T=3.69\) s.

Closed-loop (ultimate-gain) method. Close the loop with P action only. Raise \(K_p\) until the output oscillates with constant amplitude: that gain is the ultimate gain \(K_u\), the oscillation period is \(P_u\).

Same plant under P control at \(K_u=8\): sustained oscillation, \(P_u=2\pi/\sqrt3=3.63\) s (the loop is on the stability boundary, note-C2 §18).

  5. Limitations: the plant must be open-loop stable; noise makes the tangent uncertain; the step must be small enough to stay near the operating point.
Open loop → step \(\Delta u\) → S-shaped reaction curve → tangent at inflection gives \(L\), \(T\) (and slope \(R\)) → settings from the Z–N table → fine-tune.

Cx.6Feedforward vs feedback and other written parts

4 parts · 14 marks · ELEC2245 2024 (Q3(c) May, Q6(c) Dec) · MECH2004 Dec 2011 · not taught in MECH2413

What you need (beyond MECH2413)

Feedforward control acts on a signal you can measure before it upsets the output: the reference \(r\) (scale it by \(K=1/G(0)\) so the steady output equals \(r\)) or a measured disturbance \(w\) (subtract \(k_pw\) at the plant input so it cancels the disturbance's effect). It uses the model to predict; it never looks at the output. Feedback (note-C1 §5–6) looks at the error \(e=r-y\) and corrects it after it appears.

Integral action gives zero steady error (note-C2 §15): if the loop \(D_cG\) contains \(1/s\) and the closed loop is stable, then at DC \(|D_cG|\to\infty\), so

\[\begin{aligned}\frac{E}{R}&=\frac{1}{1+D_cG}\to0,\\\frac{Y}{W}&=\frac{1}{1+D_cG}\to0.\end{aligned}\]

In words: the integrator keeps changing the control signal for as long as any error remains, so the only steady state is zero error.

Free variable (block-diagram language in MECH2004): a signal that no other signal in the diagram determines, i.e. an external input. Every other signal is a dependent variable.

Negative gain on a root locus: with \(K\lt0\), \(1+KL=0\) becomes \(L=1/|K|\), so the angle condition changes from 180° to 0° (the “complementary” locus). Real-axis segments, asymptote angles and departure angles all change; the centre does not.

Why compare: feedforward is fast and cannot destabilise, but is only as good as the model; feedback is robust to the unknown, at the price of reacting late and of stability risk. Real systems use both.

Hint

With unity feedback, \(Y/W=1/(1+D_cG)\). What must \(D_c\) contain to make this zero at \(s=0\)?

Solution
  1. Yes. With unity negative feedback and the disturbance at the output, \(\dfrac YW=\dfrac{1}{1+D_c(s)G(s)}\). For a unit step \(w\), the final-value theorem (valid if the closed loop is stable) gives \(y_{ss}=\dfrac{1}{1+D_c(0)G(0)}\); this is zero only if \(D_c(0)\to\infty\): the controller needs an integrator.
  2. Controller: PI, \(D_c=K+\dfrac{K_I}{s}\). Characteristic equation \(s^3+(5+K)s^2+(6+K+K_I)s+K_I=0\); Routh: stable if \(K\gt-5\), \(K_I\gt0\) and \((5+K)(6+K+K_I)\gt K_I\). Example \(K=1\), \(K_I=1\): \(s^3+6s^2+8s+1\), stable.

    The feedback answer: unity negative feedback with a PI controller; the disturbance \(W\) still adds at the output, and need not be measured.

  3. Feedforward, advantages: it cancels the disturbance as it arrives, before any error appears; it adds no loop, so it cannot destabilise the system; simple (one gain).
  4. Feedforward, disadvantages: \(W\) must be measured; cancellation needs an exact model: \(k_p=6\) works only if \(G(0)=\frac16\) exactly (if the real \(G(0)\) is 10 % higher, with \(K=1\), \(y_{ss}=-0.085\) per unit disturbance, not 0); it cannot correct unmeasured disturbances or model drift.
  5. Feedback has the opposite profile: no disturbance sensor, robust to model error (the integrator removes any constant error), but it reacts only after the error appears and must be designed for stability.
