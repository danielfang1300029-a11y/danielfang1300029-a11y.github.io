Self-contained revision packs for HKU courses: chapter notes that teach every handout from scratch, and exam guides that solve the past papers by question type. Pick a course to open its Start Here page. New here? Read how the packs work first.

How the packs work

Every pack has the same two parts and is used the same way. Each course's Start Here page links to every page in its pack and covers what is specific to that course: the exam format, what the formula sheet gives you, and any labels that pack uses.

Part 1 · Chapter notes

Learn the ideas

What it is: one page per chapter or lecture. Every point in the course handouts is explained from scratch in plain language, with graphs, worked examples, common mistakes and concept checks. You do not need the handouts open.

Use it when: you meet a topic for the first time, you missed the lecture, or an exam-guide solution uses an idea you do not understand.

Part 2 · Exam guide

Know what the exam asks

What it is: one page per chapter. It does not re-teach. It shows where the topic appears on the paper, which question types come up and how often, and a fixed method for each type. Every past-paper question is written out in full and solved.

Use it when: you understand the topic and want to practise real exam questions, or you are in the last weeks before the exam.

A study loop

  1. Read a chapter note.
  2. Try its concept checks, then its exam taster: a few real past-paper questions at the end of the note.
  3. Follow a taster's Guide link to that question type in the exam guide and work through the rest of the questions of that type.
  4. Stuck on an idea in a solution? The guide's Chapter note links go back to the section that teaches it.

Practising a past-paper question

  1. Try it yourself first, using the method for its type.
  2. Open the Hint only if you are stuck. It names the question type and the first step.
  3. Open the Solution only once you have an answer. It is a full worked solution in numbered steps.

Each question is tagged with its paper, question number and marks. A question that was set again in a later paper is solved once, with the other sittings noted.

Things you can rely on

  • Checked answers. Every answer has been verified by computer (the sympy algebra system, plus numerical checks).
  • Flagged problems. Where a paper has a misprint, inconsistent data or an unreadable part, the question says so and states which reading is used.
  • Labelled extras. Anything not in the course handouts sits in a Beyond the handouts box, so you can tell what the lecturer actually covered.
